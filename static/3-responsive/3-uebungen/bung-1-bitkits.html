Ein tiefer Griff in die Mottenkiste und wir stoßen auf einen alten Screenshot der Seite https://www.uppercussion.com/products/bitkits. Es handelt sich dabei um die Produktseite einer Sample-Bibliothek mit 8-Bit-Sounds für Chiptunes und ähnliche Musik. Die Seite sieht eigentlich ganz nett aus, wurde aber nicht für mobile Geräte optimiert, wie die folgenden Screenshots zeigen:

Desktop-Ansicht der Vorlage
Mobile Ansicht der Vorlage

Rufen Sie den „Responsive Mode“ Ihres Browsers auf und beginnen Sie damit, die mobile Darstellung der Seite zu entwickeln. Diese sollte möglichst genau den folgenden Screenshots entsprechen. Achten Sie hier insbesondere auf die Details wie die verschiedenen Farben oder auch das Padding von Überschrift und Text, die beide absolut bündig ausgerichtet sind, obwohl der linke Rahmen der Überschrift scheinbar über den Rand hinaus ragt.

Erweitern Sie die Webseite nun so, dass sie auf großen Endgeräten so wie im folgenden Screenshot aussieht. Die Breite des Inhalts ist dort auf 60em begrenzt und auch die Schrift ist ein klein wenig größer. Die Hauptinhalte werden zusätzlich in drei Spalten nebeneinander dargestellt.

  • Für die Texte können Sie irgendwelche Dummytexte verwenden. Zum Beispiel Lorem Ipsum.

  • Für die Begrenzung der Breite und die Anordnung in Spalten müssen weitere HTML-Elemente eingebaut werden.

  • Folgender CSS-Code bringt ein HTML-Element der Klasse flexbox dazu, seine Kindelemente nebeneinander anzuordnen:

    .flexbox { display: flex; justify-content: space-between; column-gap: 1em; } .flexbox > * { flex: 1; }

  • Damit das Soundcloud-Widget funktioniert, muss die Seite über einen lokalen Webserver aufgerufen werden.

Ältere Webseiten sind, auch wenn sie sonst sehr gut aussehen, nicht immer für mobile Geräte gemacht. In dieser Aufgabe wollen wir daher eine reale Webseite nach dem Mobile-First-Prinzip nachbauen, um sie auch für moderne Endgeräte nutzbar zu machen. 📱
