Responsive Webdesign

  • Fangen Sie immer mit der mobilen Darstellung an und arbeiten Sie sich schrittweise hoch.
  • One size doesn't fit all! Versuchen Sie daher nicht, dasselbe Layout auf allen Geräteklassen umzusetzen.
  • Nutzen Sie stattdessen Media Queries, um einzelne CSS-Eigenschaften nur für große Bildschirme zu aktivieren.
  • Ordnen Sie auf kleinen Bildschirmen die wichtigsten Elemente untereinander und maximal breit an.
  • Nutzen Sie den horizontalen Platz auf großen Geräten, um bestimmte Elemente nebeneinander anzuordnen.
  • Wählen Sie für jede Geräteklasse eine angenehm lesbare Schriftgröße.
  • Vermeiden Sie verspielte Schmuckschriften, da sie auf mobilen Geräten nur schwer lesbar sind.
  • Versuchen Sie, immer den einfachsten Code zu schreiben, der Sie zum Ziel bringt.
  • Prüfen Sie, falls möglich, Eigenschaften wie die Anzahl darstellbarer Zeichen anstelle absoluter Pixelgrößen.
  • Blenden Sie alle überflüssigen Seitenleisten, Navigation, Fußzeile und Hintergründe aus, wenn Ihre Seite gedruckt wird.

CSS-basierte Layout Grids

  • Erlernen Sie die Nutzung von CSS-basierten Layout-Grids wie dem von Bootstrap.
  • Gewöhnen Sie sich insbesondere an, sie konsequent einzusetzen.
  • Prüfen Sie aber dennoch, ob die Darstellung auf allen Geräteklassen Ihren Vorstellungen entspricht.
  • Insbesondere Abstände wie Padding und Margin müssen mit Media Queries weiterhin justiert werden.
  • Wenn sich ein besonders komplexes Layout damit nicht darstellen lässt, überlegen Sie sich ein einfacheres.

Sonstige Tipps und Tricks

  • Schauen Sie sich möglichst viele mobile Apps und gut gestaltete Webseiten an, um davon zu lernen.
  • Machen Sie sich auch mit anderen CSS-Layoutmodulen wie „Flexbox“ oder „Grid“ vertraut.
  • Probieren Sie unterschiedliche CSS-Frameworks aus und versteifen Sie sich nicht auf ein einzelnes.
  • Wählen Sie stattdessen für jedes Projekt das passende Framework aus. Es muss nicht immer Bootstrap sein.
  • Oder nutzen Sie für kleine bis mittlere Anwendungen gar kein Framework, wenn es keinen Mehrwert bietet.

Hier nochmal das Wichtigste in aller Kürze. Auf dieser Seite haben wir wie immer ein paar allgemeine Tipps zusammengestellt, worauf Sie beim Webdesign achten sollen.
