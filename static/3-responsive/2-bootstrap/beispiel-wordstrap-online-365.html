    Bootstrap eignet sich hervorragend dazu, auch komplexe Anwendungs-UIs zu gestalten, wie das folgende Beispiel zeigt. Hier haben wir die Benutzungsoberfläche einer typischen Textverarbeitung wie Word oder LibreOffice Writer mit Bootstrap nachgebaut. Die Besonderheit dabei ist, dass das Beispiel fast vollständig mit HTML ohne eigenen CSS-Code programmiert wurde. Möglich machen dies die vielen CSS-Klassen von Bootstrap, mit denen die Gestaltung eines HTML-Elements mit dem class-Attribut direkt im HTML-Quellcode erfolgen und dabei sogar die aktuelle Bildschirmgröße berücksichtigen kann.

    Natürlich ist der HTML-Code hier sehr viel unübersichtlicher als bei einer Version mit klassischem Stylesheet. Jedoch kann man argumentieren, dass es bei komplexen Layouts einfacher ist, Inhalt und Darstellung zusammen zu definieren, anstatt mit HTML und CSS zwei umfangreiche, getrennte Quellcode-Dateien bearbeiten zu müssen. Moderne Frameworks wie Bootstrap oder TailwindCSS gehen daher diesen Weg. Letztlich bleibt es aber eine Geschmacksfrage, welchen Weg man bevorzugt.

    Fahren Sie mit der Maus über die einzelnen Bereiche des Beispiels. Wenn diese dabei farblich hervorgehoben werden, können Sie sie anklicken, um ihren Quellcode zu sehen.
