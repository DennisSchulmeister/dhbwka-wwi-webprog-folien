In dieser Aufgabe wollen wir das Gridlayout von Bootstrap ausprobieren und damit eine kleine Kachelwand mit Urlaubsbildern erstellen. Laden Sie sich daher das Vorlageprojekt zu dieser Aufgabe herunter (oder starten Sie die Online-IDE), damit Sie einen Grundstock an Bildern haben und programmieren Sie die unten dargestellte Seite nach.

Farbcodes

  • Die Farbe der Überschrift nennt sich crimson.
  • Der Farbcode der roten Kachel ist #880033.
  • Der Farbcode der blauen Kachel ist #005987.
  • Der Farbcode der grünen Kachel ist #1B8D68.
  • Die Schriftfarbe ist weiß.

Abstände

  • Mit <div class="row g-0"> lässt sich der Abstand zwischen den Kacheln entfernen.
  • Als Innenabstand bieten sich 0.5em an.

Bilder

  • Die Bilder sollten als Blockelemente mit 100% Breite und 100% Höhe formatiert werden.

  • Alternativ können die Bilder auch im Stylesheet als Hintergrundbilder gesetzt werden:

    .col { background-size: cover; background-position: center; } .bild1 { background-image: url(auto.jpg); }
