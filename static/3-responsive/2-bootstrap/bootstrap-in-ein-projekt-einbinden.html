• Bootstrap besteht lediglich aus einem Stylesheet und einer optionalen JavaScript-Datei¹.
  • Diese können am einfachsten über ein Content Delivery Network eingebunden werden.
  • Auf der Webseite von Bootstrap wird hierfür jsDelivr empfohlen.

  • Im HTML-Code müssen dann nur folgende Zeilen eingebaut werden.²

    • <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" /> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

    ¹ Es handelt sich dabei um die für den Produktiveinsatz optimierte Version, die aus den eigentlichen Quelldateien gebaut und minifiziert wird.

    ² Hier wird Bootstrap-Version 5.3.3 eingebunden. Auf der Startseite von getboostrap.com finden sich unter „Include via CDN“ eventuell neuere Links.

    Vollständige Vorlage

    Der folgende Quellcode entspricht im Wesentlichen der Vorlage von der Bootstrap-Webseite mit den im Video erklärten Anpassungen.

    <!DOCTYPE html> <html lang="de"> <head> <title>Hallo, Bootstrap!</title> <meta charset="utf-8" /> <meta name="viewport" content="width=device-width, initial-scale=1" /> <!-- Bootstrap --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" /> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script> </head> <body> <!-- Seiteninhalt hier --> </body> </html>

    Auf getbootstrap.com erscheint sich gleich am Anfang ein Download-Button.

    Hier können vorkompilierte CSS- und JavaScript-Dateien heruntergeladen werden.

    Die ZIP-Datei kann direkt im Projektverzeichnis entpackt werden.

    So sollte die entpackte Verzeichnisstruktur aussehen. Der Einfachheit halber wurde das Bootstrap-Verzeichnis hier in bootstrap umbenannt.

    Wahlweise können einzelne Teile von Bootstrap oder das gesamte Framework eingebunden werden (Dokumentation hierzu). Soll das gesamte Framework genutzt werden, werden nur die folgenden Dateien benötigt.

    Im Projektverzeichnis sollte eine Datei namens index.html mit folgendem Inhalt angelegt werden. Im Vergleich zur CDN-Variante unterscheiden sich hier nur das <link> und <script>-Element.

    <!DOCTYPE html> <html lang="de"> <head> <title>Hallo, Bootstrap!</title> <meta charset="utf-8" /> <meta name="viewport" content="width=device-width, initial-scale=1" /> <!-- Bootstrap --> <link rel="stylesheet" href="bootstrap/css/bootstrap.min.css" /> <script src="3-responsive/bootstrap/js/bootstrap.bundle.min.js"></script> </head> <body> <!-- Seiteninhalt hier --> </body> </html>

    Paketverwaltung

  • In der professionellen Webentwicklung werden häufig Package Manager genutzt.
  • Beispiele hierfür sind der Node Package Manager oder Yarn.
  • Diese laden alle benötigten Bibliotheken und Frameworks aus einem zentralen Repository.
  • Zusätzlich wird dann noch ein Bundler wie Webpack oder Parcel benötigt.
  • Denn der Package Manager lädt die Pakete nur herunter. Der Bundler kopiert die Dateien in das Projekt¹.
  • Sind beide Voraussetzungen gegeben, kann Bootstrap mit einem Befehl wie dem folgenden installiert werden:
    • npm install bootstrap

    ¹ Dies ist eine stark vereinfachte Darstellung. Bundler bauen aus dem Quellcode einer Anwendung sowie den Quellcodes aller benötigten Bibliotheken so genannte Bundles, die vom Browser geladen und ausgeführt werden können. Auf diese Weise wird nicht nur die Integration externer Bibliotheken vereinfacht, da ihre Dateien nicht manuell in das Projekt kopiert werden müssen. Auch die Ladezeiten können optimiert werden, indem viele kleine Dateien zu einer größeren Datei zusammengefasst und anschließend minifiziert werden. Immer besser funktioniert dabei auch das so genannte „Tree Shaking“, durch das alle nicht benutzten Teile aus dem Quellcode entfernt werden.

    Import Maps

    Ein aktuell noch in Entstehung befindlicher Standard sind Import Maps, mit denen die Verwaltung externer Abhängigkeiten in der Frontend-Entwicklung künftig deutlich vereinfacht wird. Der Einsatz von Package Managern und Bundlern wird dadurch in vielen Projekten überflüssig werden. Da der Standard aber noch nicht ratifiziert wurde (Stand: September 2022), wird er derzeit nicht von allen Browsern unterstützt. Siehe Can I Use: Import Maps.

    Lediglich zwei Dateien werden benötigt, um Bootstrap in ein Projekt einzubinden: Das Bootstrap-Stylesheet und optional der dazugehörige JavaScript-Code. Sollen die vordefinierten UI-Elemente von Bootstrap nicht genutzt bzw. ihre Logik von Hand ausprogrammiert werden, genügt sogar nur das Stylesheet. Beide Dateien werden von den Bootstrap-Entwicklern anhand der Quellcodes von Bootstrap zusammengebaut und minifiziert, um die Ladezeiten zu optimieren. Das Framework kann somit leicht eingebunden werden, wobei hierbei drei Alternativen zur Verfügung stehen:

    1. Content Delivery Network: Am einfachsten ist die Einbindung über ein Content Delivery Network (kurz: CDN), da hierfür leidglich zwei Zeilen im HTML-Code ergänzt werden müssen. Die Dateien werden dabei von den weltweit gespiegelten Servern des Content Delivery Network geladen.
    2. Manueller Download: Will man sich nicht von fremdbetriebenen Servern abhängig machen, oder soll die Seite auch ohne permanente Internetverbindung ausführbar sein, können die zu integrierenden Dateien auch manuell heruntergeladen und in das eigene Projekt übernommen werden.
    3. Paketverwaltung: Je mehr Bilbiotheken und Frameworks in einem Projekt genutzt werden und je mehr diese von anderen Bibliotheken abhängen, desto aufwändiger und fehleranfälliger ist es, diese im Internet zu suchen und in das Projekt zu übernehmen. In vielen Projekten übernimmt diese Aufgabe heute daher ein Werkzeug zur Paketverwaltung.

    Auf dieser Seite werden die ersten beiden Alternativen vorgestellt, wobei von diesen meist die Variante mit dem Content Delivery Network zu bevorzugen ist. Denn auf diese Weise können Synergieeffekte mit anderen Seiten genutzt werden, in denen dieselbe Bootstrap-Version zum Einsatz kommt, da die Dateien dann ohne Zeitversatz aus dem Browser-Cache geladen werden. Außerdem haben Bundler und Werkzeuge zur Paketverwaltung das manuelle Suchen und Herunterladen von Bibliotheken inzwischen weitgehend verdrängt, so dass dies heutzutage nur noch in speziellen Fällen notwendig ist. Da hierfür aber umfangreiche Werkzeuge benötigt werden, die wir bisher noch nicht betrachtet haben, fehlt diese Möglichkeit hier.
