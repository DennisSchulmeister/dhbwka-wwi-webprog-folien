Sorgt dafür, dass bestimmte Elemente beim Drucken untereinander stehen und keinen Hintergrund haben.

@media screen (min-width: 800px) { #main_parent { display: flex; } }

Schaltet für ein Element den Flexbox-Algorithmus ein, wenn der Bildschirm mindestens 800px breit ist.

@media (orientation: landscape) { html { background-image: url(landscape.jpg); } }

Setzt ein spezielles Hintergrundbild, wenn die Webseite im Querformat angezeigt wird.

Nachdem wir geräteabhängige Fallunterscheidungen anhand von Media Queries eben im Video schon gesehen haben, sollen hier nun ihre Syntax und wesentlichen Funktionen als Kurzreferenz dargestellt werden. Wir sehen hier nochmal in kompakter Weise, wie spezifische CSS-Anweisungen in Abhängigkeit bestimmter Ausgabegeräte sowie deren Eigenschaften aktiviert werden können. Wie wir aber auch sehen werden, kann man nicht direkt abfragen, ob die Darstellung auf einem Smartphone, Tablet oder Desktop-Computer erfolgt, da aus Sicht von CSS alle einen Bildschirm besitzen und man nur prüfen kann, ob die Ausgabe zum Beispiel auf einem Bildschirm oder auf Papier erfolgt. Jedoch lassen sich die Eigenschaften der Bildschirme abprüfen, was im Grunde genommen auch die sinnvollere Variante ist.

Grundsätzliche Syntax

Media Queries prüfen immer zwei Dinge gleichzeitig ab: Das verwendete Ausgabegerät sowie dessen Eigenschaften. Dementsprechend setzen sie sich aus dem Namen des zu prüfenden Geräts und in Klammern dahinter zusätzlichen Prüfungen zusammen. Beide Teile sind dabei optional, was entweder bedeutet, dass eine Eigenschaft für alle möglichen Geräte geprüft oder nur das Gerät selbst ohne weitere Einschränkung abgefragt wird. Die generelle Syntax für alle drei Formen ist:

ausgabemedium (eigenschaft: wert)

Da beide Teile optional sind, solange der jeweils andere Teil vorhanden ist, sind aber auch folgende Varianten erlaubt:

  • ausgabemedium
  • (eigenschaft: wert)

Welche Ausgabemedien es gibt, und welche Eigenschaften für diese geprüft werden können, steht im Hauptbereich dieser Seite. Beispielsweise steht das Gerät screen für beliebige Bildschirme und print für die Ausgabe auf dem Drucker. Innerhalb dieser Geräteklassen gibt es dann aber keine weiteren Unterschiede mehr, so dass insbesondere nicht einfach zwischen Smartphone, Tablet oder Desktop-Computer unterschieden werden kann. Diese müssen stattdessen über ihre Eigenschaften ermittelt werden:

  • min-width: Mindestbreite des Viewports1
  • max-width: Maximale Breite des Viewports1
  • orientation: portrait (Hochformat), landscape (Querformat)
  • …

Sollen mehrere Bedingungen gleichzeitig geprüft werden, können mehrere Media Queries mit UND und ODER verknüpft werden:

  • UND-Verknüpfung (mit and):
    (orientation: landscape) and (max-width: 600px)

  • ODER-Verknüpfung (mit Komma):
    (orientation: landscape), (min-width: 1024px)

1 Der Viewport entspricht dem sichtbaren Bereich einer Seite. In der Regel hat dieser dieselbe Größe wie das Browserfenster. Im Responsive-Design-Modus kann jedoch zum Testen nur der Viewport verkleinert werden, ohne das Browserfenster zu verändern.

Verwendung im HTML-Code

Innerhalb von HTML können Media Queries nur an sehr wenigen Stellen direkt verwendet werden. Die wichtigste davon ist das <link>-Element zum Einbinden eines Stylesheets. Indem dort ein Media Query eingefügt wird, können bestimmte Stylesheets nur für bestimmte Ausgabegeräte geladen werden:

<link rel = "stylesheet" media = "print" href = "print.css" /> <link rel = "stylesheet" media = "screen and (max-width: 40em)" href = "phone.css" />

Meist wird diese Möglichkeit genutzt, um allgemeingültige Layoutangaben in einem zentralen Stylesheet zu verpacken und zusätzlich zu diesem gerätespezifische Stylesheets nachzuladen. Oft wird es auch genutzt, um für die Bildschirmdarstellung und Druckausgabe weitgehend eigenständige Stylesheets zu definieren.

Verwendung im CSS-Code

Die meiste Verwendung finden Media Queries innerhalb von Stylesheets, da hier ganze Regelblöcke dadurch ein- oder ausgeschaltet werden können. Dabei ist allerdings zu beachten, dass dies nur auf der obersten Ebene in einem Stylesheet erlaubt ist und insbesondere innerhalb der geschweiften Klammern eines Regelblocks keine Media Queries erlaubt sind.2 Die Prüfung selbst wird durch die Anweisung @media wie im folgenden Beispiel eingeleitet:

@media screen (min-width: 800px) { html { font-size: 14pt; } #main_parent { display: flex; } }

Folgender Quellcode funktioniert stattdessen leider nicht:

main { background: white; padding: 1em; box-shadow: 0px 0px 2px rgba(0,0,0, 0.5); @media screen (min-width: 800px) { display: flex; } }

Im Hauptbereich ist darüber hinaus noch eine Variante dargestellt, bei der mit @import geräteabhängig weitere Stylesheets importiert werden können.

2 Präprozessoren wie Less und Sass können hier Abhilfe schaffen.
