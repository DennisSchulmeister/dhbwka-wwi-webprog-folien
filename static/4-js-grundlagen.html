Nach Abschluss dieser Einheit können Sie …

  • die Einsatzgebiete von JavaScript innerhalb und außerhalb des World Wide Web beurteilen.
  • JavaScript direkt im Browser ausprobieren, ohne einen lokalen Editor starten zu müssen.
  • das Prinzip der dynamischen, schwachen Typisierung erklären und die Unterschiede zu Java aufzeigen.
  • eigene Funktionen in JavaScript implementieren und darin lokale und globale Variablen verwenden.
  • Rückruffunktionen und Funktionen höherer Ordnung schreiben.
  • mit Arrays und Listen die wichtigsten Datentypen von JavaScript verwenden.
  • eigene Daten im JSON-Format codieren.
  • JavaScript-Code in Ihre eigenen HTML-Dateien einbinden und damit das Document Object Model manipulieren.
  • JavaScript-Code debuggen und Fehler darin beheben.

Eigentlich ist ja Java die Sprache der Wahl, wenn es um das Programmierenlernen an der DHBW geht. Doch im Web kommen wir an JavaScript nicht vorbei, da es die einzige imperative Programmiersprache ist, die der Browser nativ ausführen kann.¹ Viele interessante Funktionen von HTML lassen sich ohne JavaScript auch gar nicht nutzen. Vor diesem Hintergrund war JavaScript deshalb lange Zeit im Browser „gefangen“, seit einiger Zeit kann man damit aber auch alle anderen Arten von Anwendungen schreiben. Dadurch wird es umso interessanter, sich mit dieser Sprache zu beschäftigen.

¹ Dank WebAssembly können inzwischen auch andere Programmiersprachen innerhalb des Browsers ausgeführt werden. Ihre Programme müssen hierfür jedoch durch einen speziellen Compiler erst nach WASM compiliert werden. Außerdem benötigen Sie immer eine HTML-Seite und etwas JavaScript-Code, um geladen und gestartet zu werden.

Zum Glück kennen Sie mit Java bereits eine sehr weit verbreitete Programmiersprache. Und zum Glück haben Java und JavaScript viele Gemeinsamkeiten. Doch genauso groß sind auch die Unterschiede. Am Anfang werden wir uns daher zunächst mit der Syntax von JavaScript beschäftigen und dabei die wesentlichen Gemeinsamkeiten und Unterschiede zu Java aufzeigen. Insbesondere die Deklaration von Funktionen sowie das Typsystem von JavaScript werden uns eine Weile beschäftigen. Darauf aufbauend erfahren Sie dann, was JSON ist und welche Datentypen es praktischerweise eingebaut hat. Die Objektorientierung lassen wir dabei zunächst außen vor. Mit ihr beschäftigen wir uns ein andermal.

Im zweiten Teil gehen wir dann in die Praxis und zeigen, wie JavaScript und HTML im Browser zusammenspielen. Hier erfahren Sie, wie JavaScript-Code in HTML eingebunden werden kann und wie auf das Document Object Model mit JavaScript zugegriffen werden kann. Die hier gezeigten Methoden sind sozusagen die elementaren Bausteine, die zur Entwicklung browserseitiger Webanwendungen genutzt werden. Die Programmierung damit ist zwar in vielen Fällen nicht so flüssig und elegant wie mit einem der vielen modernen Frameworks für JavaScript (z.B. Angular, Vue oder React). Dennoch können sämtliche Webanwendungen damit programmiert werden, da die Frameworks die Arbeit mit dem Document Object Model für den Entwickler mehr oder weniger lediglich weg abstrahieren, aber eben nicht ersetzen. Als kleine Übung dürfen Sie am Ende des Kapitels daher auch eine echte JavaScript-Anwendung debuggen, um einen kleinen, aber gemeinen Fehler darin zu beheben.
