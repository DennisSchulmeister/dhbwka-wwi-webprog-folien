In diesem Teilkapitel wollen wir uns mehr mit dem Zusammenspiel von HTML und JavaScript beschäftigen. Aus diesem Grund siehst du hier nochmal Beispiele dafür, wie JavaScript in eine HTML-Datei eingebunden werden kann. Wie du siehst, ist es nicht anders, als mit CSS. Auch da hast du die Wahl, ob du den Code direkt in die HTML-Seite einbauen oder in eine eigene Datei auslagern willst. Doch im Gegensatz zu CSS gibt es für JavaScript keine zwei unterschiedlichen HTML-Tags. Für beide Varianten wird stattdessen das <script>-Tag verwendet.

Willst du den JavaScript-Code direkt in die HTML-Datei schreiben, machst du das wie unten gezeigt. Das <script>-Element darf dabei sowohl im <head> als auch im <body> stehen.

<script> sagHallo = () => { console.log("Hallo, Welt!"); } </script>

Willst du den JavaScript-Code stattdessen auslagern, machst du das so:

<script src="4-js-grundlagen/script.js"></script>

Dabei ist allerdings ganz wichtig, dass sich das <script>-Tag nicht selbst schließen darf! Du brauchst also zwingend immer auch das schließende </script>-Tag. <script … /> ist nicht erlaubt.
