Die Webseite der DHBW Karlsruhe enthält einen schön gemachten 360°-Fotorundgang, auf dem man verschiedene Gebiete innerhalb und außerhalb des Campus erkunden kann. Eine dreidimensionale Projektion können wir in dieser Aufgabe zwar nicht nachbauen (auch wenn es mit three.js oder einer ähnlichen WebGL-Bibliothek nicht allzu schwer ist). Wir können die Seite aber wie immer als Vorlage für unsere eigenen Experimente nutzen und die wesentlichen Gestaltungsmerkmale in Form eines digitalen Fotobuchs nachbauen.

Im unteren Bereich der Seite soll eine Reihe von Vorschaubildern zur Auswahl des aktuell sichtbaren Bildes angezeigt werden. Diese soll auf kleinen Bildschirmen auf drei Bilder bestehend aus dem aktuellen, dem vorherigen und dem nachfolgenden Bild beschränkt werden. Bei Klick auf ein Bild soll das aktuelle Hintergrundbild durch dieses ersetzt werden, wobei der Wechsel durch eine mit CSS realisierte, animierte Überblendung erfolgen soll. Das aktuelle Vorschaubild soll visuell hervorgehoben werden, wenn die Maus darüber fährt, indem die anderen Vorschaubilder halbtransparent gemacht werden.

Die zu bearbeitenden Stellen sind wie immer mit TODO im Quellcode gekennzeichnet und ausführlich beschrieben. Sie sollten in der durch die Nummerierung vorgegebenen Reihenfolge abgearbeitet werden:

  1. Weitere Bilder im HTML-Code deklarieren.
  2. Anklickbare Vorschaubilder generieren.
  3. Beim Start das erste Bild anzeigen.
  4. Hintergrundbild mit Animation wechseln.

Es muss kein CSS-Code geschrieben werden. Lediglich eine Stelle im HTML-Code muss angepasst werden. Die eigentliche Arbeit liegt im JavaScript-Code, in dem einfach die TODO-Kommentare abgearbeitet werden müssen.

Mit HTML, CSS und JavaScript kann man schon tolle Dinge machen. Im Handumdrehen entstehen ansprechende User Interfaces und interaktive Anwendungen. Hier wollen wir ein kleines Fotobuch zum Durchblättern von Urlaubsbildern damit programmieren. 📷
