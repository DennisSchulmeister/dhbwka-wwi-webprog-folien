Grundregeln für guten JavaScript-Code

  • Leserlicher, gut kommentierter Code ist auch in JavaScript King!
  • Nutzen Sie modernes JavaScript (ES6 oder neuer) anstelle veralteter Techniken.
  • Ignorieren Sie deshalb alle JavaScript-Tutorials von vor 2015. Sie sind alle veraltet.
  • Nutzen Sie keine globalen Variablen, wenn es nicht absolut sein muss.
  • Deklarieren Sie lokale Variablen immer mit let oder var.
  • Verwenden Sie in neuem Code jedoch immer let anstatt var.
  • Nutzen Sie die Pfeilsyntax für Funktionen anstelle von function.
  • Nutzen Sie function nur für globale nicht-anonyme Funktionen.
  • Vergleichen Sie zwei Werte möglichst immer mit === anstatt mit ==.
  • Dadurch sind zwei Werte nur dann gleich, wenn sie auch denselben Typ besitzen.
  • Beschäftigen Sie sich mit Promises und nutzen Sie sie wo sinnvoll.
  • Nutzen Sie async und await, um die Arbeit mit Promises zu vereinfachen.
  • Beschäftigen Sie sich wenigstens in Grundzügen mit der Objektorientierung in JavaScript.

DOM-Manipulation mit JavaScript

  • Nutzen Sie querySelector() und querySelectorAll(), um komplizierte DOM-Zugriffe zu vereinfachen.
  • Vermeiden Sie direkte Änderungen am style-Attribut eines DOM-Elements.
  • Schalten Sie stattdessen mit element.classList einzelne Stylesheet-Regeln ein oder aus.
  • Versuchen Sie, möglichst viele DOM-Manipulationen in einer zentralen Methode zu sammeln.
  • Nehmen Sie DOM-Manipulationen keinesfalls wo Sie gehen und stehen überall im JS-Code vor.
  • Nutzen Sie Frameworks wie jQuery nur, wenn Sie mit reinem JavaScript nicht weiter kommen.
  • Die Standardklassen von JavaScript können mehr als Sie denken oder die Frameworks zugeben.

Nützliche Werkzeuge

  • Machen Sie ausgiebigen Gebrauch von der JavaScript-Konsole und dem Debugger Ihres Browsers.
  • Nutzen Sie das von node.js bekannte npm, um die Abhängigkeiten in Ihren Projekten zu verwalten.
  • Andere Werkzeuge wie Bower oder Browserify sind inzwischen schon nicht mehr modern.
  • Nutzen Sie Packer wie esbuild oder Parceljs, um die Ladezeiten Ihrer Seiten zu optimieren.
  • Nutzen Sie sie außerdem, um Ihren JavaScript-Code in sauber gekapselte Module zu teilen.
  • Lernen Sie aber erst die Sprache selbst und beschäftigen Sie sich erst dann mit den Werkzeugen!
