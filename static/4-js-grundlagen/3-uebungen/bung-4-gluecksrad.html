Mit dem bisher erworbenen Wissen können wir sogar kleine Browser-Spiele programmieren. Denn mit HTML und CSS lassen sich diese einfach gestalten, wobei JavaScript die Spiellogik beisteuert. In dieser Aufgabe wollen wir daher ein kleines Ratespiel in Anlehnung an die Spielshow Glücksrad programmieren. Genau wie im Original müssen bei uns Buchstaben für ein Lösungswort erraten werden. Für jeden richtigen Buchstaben werden Punkte gutgeschrieben, für jeden falschen Buchstaben wieder abgezogen. Passende Geräuscheffekte begleiten das Spiel. ♪

Die zu bearbeitenden Stellen sind mit TODO im Quellcode gekennzeichnet. Los geht es in der Datei index.html, in der ein neues Objekt der Klasse WheelOfFortune erzeugt werden muss. Die Syntax ist ähnlich wie in Java. Anschließend müssen in der Klasse ein paar DOM-Zugriffe ausprogrammiert werden, um das Spiel fertigzustellen.

Auch Spiele lassen sich mit HTML, CSS und JavaScript umsetzen. Hier wird ein kleines Spiel entwickelt, das von der seit 1988 laufenden Spielshow Glücksrad inspiriert ist.
