Vor der Verabschiedung von HTML 5 waren HTML und JavaScript noch ziemlich getrennt. Zwar gab es von Anfang an die Möglichkeit, die Elemente einer Webseite mit JavaScript über das Document Object Model zu beeinflussen, mehr Integration war aber nicht vorgesehen. Ein Grund dafür war sicher, dass die vorherige HTML-Version schon 1999 zur einer Zeit verabschiedet wurde, als das Web tatsächlich fast nur aus einfachen Webseiten bestand.

Innerhalb der folgenden 15 Jahre 📆 hatten sich die Art der Webseiten und der Umfang der Webanwendungen jedoch grundlegend verändert. Und auch außerhalb des Browsers hat JavaScript immer mehr Anhänger gefunden. Deshalb hat es mit HTML 5 dann auch so lange gedauert. HTML, CSS und JavaScript waren plötzlich „eine Einheit“, die sowohl innerhalb als auch außerhalb des Browsers daheim sein kann. Dies musste bei der Spezifikation natürlich hinreichend berücksichtigt werden.

Im Vergleich zu seinen Vorgängern ist HTML 5 daher eine komplette Neuorientierung. Neben den üblichen Definitionen vieler neuer HTML-Elemente umfasst der Standard auch eine Vielzahl von JavaScript-Klassen und APIs für ganz unterschiedliche Aufgaben, was so zuvor nicht gegeben hat. 📑 Viele Funktionen, wie zum Beispiel das <video> oder <canvas>-Element, lassen sich ohne JavaScript deshalb nur sehr sehr eingeschränkt nutzen.

Damit einher geht auch ein neues Verständnis für das Web. Anstelle eines einfachen Informationssystems zum Abruf textartiger Webseiten wird das WWW heute immer mehr als vollwertige Anwendungsplattform verstanden, deren Bestandteile zur Entwicklung fast beliebiger Anwendungen genutzt werden können (sofern diese im Browser laufen).
