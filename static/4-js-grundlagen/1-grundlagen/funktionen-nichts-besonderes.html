Verglichen mit anderen Programmiersprachen sind Funktionen in JavaScript sehr mächtig. Die Möglichkeit, eine Funktion als Referenz an eine andere Funktion zu übergeben, oder Funktionen zu schreiben, die neue Funktionen als Ergebnis zurückliefern, prägen die Programmierung in JavaScript nachhaltig.

Häufig erwartet eine Funktion eine andere Funktion als Parameter, um diese bei Eintreten eines Ereignisses aufrufen zu können. Die aufgerufene Funktion nennt man Rückruffunktion oder auch Callback:

let callback = () => { … }; let div = document.getElementById("theater"); div.addEventListener("click", callback);

Wichtig zu verstehen ist hier, dass die Funktion callback in Zeile drei nicht direkt aufgrufen, sondern als Referenz an die Methode addEventListener übergeben wird. Dadurch kann die Funktion zu einem späteren Zeitpunkt – wenn das überwachte Ereignis eintritt – asynchron aufgerufen werden. Da Funktionen sehr oft als Parameter an andere Funktionen übergeben oder als Event Handler eingesetzt werden müssen, lässt sich die Schreibweise noch weiter verkürzen:

let div = document.getElementById("theater"); div.addEventListener("click", () => { … });

Funktionen höherer Ordnung sind Funktionen, die als Rückgabewert eine neue Funktion liefern:

let erzeugeFunktion = name => { return () => `Hello, ${name}!`; } let begruesseKitty = erzeugeFunktion("Kitty"); console.log(begruesseKitty());

Gibt auf der Konsole Hello, Kitty! aus.

Das Video zeigt, warum Funktionen in JavaScript gewöhnliche Objekte sind und welche weitreichenden Konsequenzen dies auf das gesamte Sprachdesign hat. Dies wird am Beispiel von Rückruffunktionen (sog. Callbacks) für HTML-Events sowie der Definition höherer Funktionen demonstriert.

Schaust du dir die neue Schreibweise für Funktionen in JavaScript genauer an, wirst du feststellen, dass sie eigentlich aus zwei Teilen besteht: Einer Variablen links vom Gleichheitszeichen und der eigentlichen Funktion rechts davon:

let getBegruessung = () => { let texte = [ "Hallo Welt!", "Sei gegrüßt, Welt!", "Willkommen auf der Welt!", "Hi!" ]; let nr = Math.floor(Math.random() * texte.length); return texte[nr]; }

Das ist auch durchaus so beabsichtigt. Denn anders als in Java waren Funktionen in JavaScript schon immer „Bürger erster Klasse“ („first-class citizen“ auf englisch). Damit ist gemeint, dass Funktionen ganz normale Objekte sind, die man einer Variable zuweisen oder einer anderen Funktion als Parameter übergeben kann. In Java ist das nicht so. Da haben Klassen und Methoden quasi einen Sonderstatus, so dass du sie zwar über ihren Namen ansprechen sonst aber nichts damit machen kannst.

Will man in Java beispielsweise eine Methode aufrufen, deren Namen man erst zur Laufzeit erfährt, muss man sich hierfür mit der „Reflection API“ herumschlagen. 😣 In JavaScript ist es hingegen ganz easy: 😎

let meinObjekt = … let nameDerMethode = input("Welche Methode willst du aufrufen?"); meinObjekt[nameDerMethode]();

Übergabe einer Rückruffunktion

Ein häufiges Muster in JavaScript ist, dass eine Funktion eine andere Funktion als Parameter übergeben bekommt, um diese bei Eintreten eines Ereignisses automatisch aufrufen zu können. Erinnere dich hierfür zum Beispiel an den Timer aus dem Vorhang-Beispiel:

window.setTimeout( () => buehne.src = buehnenbilder[aktuellesBild], 2100 );

Der Methode window.setTimeout wird im ersten Parameter eine Funktion übergeben, die nach Ablauf der Zeit automatisch aufgerufen wird. Doch auch bei der Verarbeitung anderer Ereignisse kommen solche Rückruffunktionen (englisch „Callbacks“) zum Einsatz:

let image = document.getElementById("clown-image"); image.addEventListener("mouseover", () => image.src = "clown2.jpg"); image.addEventListener("mouseout", () => image.src = "clown1.jpg");

Hier wird in der ersten Zeile ein <img>-Element im Document Object Modul gesucht. Anschließend werden zwei Event Handler für die Ereignisse mouseover (Maus fährt in das Bild hinein) und mouseout (Maus verlässt das Bild wieder) registriert. Bei den Event Handlern handelt es sich dabei um an Ort und Stelle definierte, namenlose Funktionen (alles ab () => …), die einfach den Dateinamen des Bilds austauschen. So kann zum Beispiel ein Effekt realisiert werden, bei dem ein weinender Clown bei Berührung zu einem lachenden Clown wird und umgekehrt. 🎭

Funktionen höherer Ordnung

Funktionen können noch viel mehr. Denn JavaScript ist in seinen Grundzügen nicht nur objekt-orientiert sondern auch eine richtige funktionale Programmiersprache. Als solche kennt es auch Funktionen höherer Ordnung, also Funktionen, die als Ergebnis eine neue Funktion zurückliefern. Viele fortgeschrittene Konzepte von JavaScript basieren auf dieser Idee. Zum besseren Verständnis hier ein relativ einfaches Beispiel:

let erzeugeFunktion = (n) => { return (m) => n * m; } let verdoppeln = erzeugeFunktion(2); let verdreifachen = erzeugeFunktion(3); console.log(verdoppeln(21)); console.log(verdreifachen(11));

Als Ergebnis gibt das Programm erst 42 und dann 33 aus. Denn die Funktion erzeugeFunktion nimmt einen Paremter n entgegen und erzeugt daraus eine neue Funktion, die selbst den Parameter m erwartet und als Ergebnis n * m zurückliefert.
