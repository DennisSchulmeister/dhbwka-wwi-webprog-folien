Das Video gibt einen kurzen Überblick zu den häufigsten Anwendungsgebieten von JavaScript und stellt diese anhand kleiner Fallbeispiele vor.

Führt man sich vor Augen, dass die ersten Ideen zum World Wide Web schon 1989 formuliert wurden und stellt man dem die Halbwertszeit typischer IT-Produkte entgegen, grenzt die ungebrochen weite Verbreitung des WWW fast an ein Wunder. Doch nicht nur, dass das Web nicht schon längst wieder in der Versenkung verschwunden ist, handelt es dabei auch noch um den mit Abstand beliebtesten und am häufigsten genutzten Dienst des Internets. Längst werden damit nicht nur einfache Webseiten sondern immer komplexere Webanwendungen, die auf immer unterschiedlicheren Arten von Endgeräten laufen können, entwickelt. Grund für diesen Erfolg waren von Anfang an die einfache Programmierbarkeit sowie die schnelle und unkomplizierte Weiterentwicklung der zugrunde liegenden Technologien, die auf diese Weise für immer mehr Anwendungsfälle nutzbar wurden, bei gleichzeitiger Kompatibilität zu sämtlichen vorhergehenden Entwicklungen.

Schon früh erkannte man deshalb, dass die Inhalte des World Wide Web nicht nur statisch sein sollten, sondern auch interaktive Elemente beinhalten können. Neben entsprechenden Möglichkeiten, serverseitig dynamische Inhalte zu generieren (indem die HTTP-Anfragen an ein Skript zur dynamischen Erzeugung einer Antwort weitergeleitet werden), wurde bereits 1995 JavaScript als im Browser laufende Programmiersprache für clientseitige Anwendungslogik entwickelt. Vorreiter war in diesem Fall die Firma Netscape, welche die neue Sprache für ihren Netscape Navigator genannten Browser (einem frühen Vorläufer von Firefox) entwickeln lies. Schnell zogen die anderen Hersteller nach, indem sie die Sprache in ihre eigenen Produkte einbauten.

Anfangs überwogen allerdings oft kommerzielle Interessen, weshalb von den Herstellern leider oft inkompatible Varianten der Sprache geschaffen wurden. Der erste Browserkrieg war entflammt. Mehr als zwanzig Jahre später sind diese Probleme längst überwunden und alle Hersteller arbeiten Hand in Hand an der Standardisierung der Webtechnologien zusammen. JavaScript und auch die anderen Webtechnologien werden daher heute in immer mehr Produkten fernab dem World Wide Web eingesetzt. So können heute ganz Problemlos auch Desktopanwendungen, Smartphone-Apps oder IoT-Devices mit JavaScript programmiert werden, wie folgender kleiner Zeitstrahl verdeutlicht:

  • 1995: Netscape und Sun entwickeln JavaScript als browserseitige Scriptsprache
  • 1996: Microsoft integriert JavaScript in den Internet Explorer
  • 1998: JavaScript wird als ECMAscript¹ herstellerunabhängig standardisiert
  • 2009: node.js bringt JavaScript auf den Server
  • 2009: Mit PhoneGap (bzw. Apache Cordova) lassen sich mobile Apps entwickeln
  • 2011: Weite Teile des GNOME-Desktop basieren auf JavaScript
  • 2012: Die Windows Runtime (heute Universal Windows Platform) unterstützt JavaScript
  • 2013: Tessel und Espruino bringen JavaScript auf kleine Microcontroller
  • 2014: Viele HTML5-Funktionen lassen sich nur zusammen mit JavaScript nutzen
  • 2015: JavaScript wird im Rahmen des ES6-Standards grundlegend überarbeitet und modernisiert

¹ European Computer Manufacturers Association
