Ziemlich cooles Beispiel, nicht? 😎 Wenn du noch nie mit JavaScript zu tun hattest, wirst du sicher nicht gleich jede Zeile verstehen. Aber allzu kompliziert ist der Quellcode dann doch wieder nicht. Zumindest sieht er ziemlich ähnlich zu dem Java aus, dass wir alle kennen und lieben. Also schauen wir uns doch mal an, was hier passiert.

HTML-Code

Eigentlich steckt der meiste Zauber im HTML- und CSS-Code 💫, da dort das komplette Aussehen der Seite und auch die Animationen zum Öffnen und Schließen des Vorhangs definiert sind. Das Einzige, was wir hier mit JavaScript machen, ist auf einen Mausklick zu warten, um daraufhin die Animationen zu starten und ein Geräusch abzuspielen. Hierfür werden am Anfang des HTML-Dokuments ein Stylesheet und eine JavaScript-Datei eingebunden:

<link rel="stylesheet" href="style.css" /> <script src="4-js-grundlagen/script.js"></script>

Im <body> befindet sich dann ein übergeordnetes <div> mit dem Attribut onclick="vorhangAufZu()". Das Attribut wird dabei auch „Event Handler“ genannt, da es festlegt, was bei Eintreten eines bestimmten Ereignisses passieren soll. In unserem Fall soll bei einem Mausklick die JS-Funktion vorhangAufZu() aufgerufen werden.

Der Rest ist ziemlich langweilig. 💤 Das <div> beinhaltet lediglich ein paar Bilder sowie ein weiteres <div> mit dem Hinweis, dass der Anwender das Bild anklicken soll. Durch die Reihenfolge der Elemente ist dabei bereits sichergestellt, dass das Bühnenbild hinter dem Vorhang und dieser hinter dem Publikum erscheint:

<div id="theater" onclick="vorhangAufZu()"> <img src="4-js-grundlagen/vorhang_buehne1.jpg" class="buehne" /> <img src="4-js-grundlagen/vorhang_links.jpg" class="links" /> <img src="4-js-grundlagen/vorhang_rechts.jpg" class="rechts" /> <img src="4-js-grundlagen/vorhang_publikum.png" class="publikum" /> <div class="hinweis"> Klicke auf das Bild! 🖱 </div> </div>

Stylesheet

Das Stylesheet sollte eigentlich weitgehend selbsterklärend sein. Zur Sicherheit wollen wir hier aber nochmal die wichtigsten Dinge zusammenfassen. Nämlich, warum die Bilder alle genau an der richtigen Stelle erscheinen und wie die Vorhanganimation realisiert wurde. Ein eigener kleiner Mikrokosmos 🌌 ist dabei folgender Block:

#theater { padding-top: 63%; position: relative; overflow: hidden; cursor: pointer; }

Diese Zeilen bewirken folgendes:

  1. padding-top: 63%: Dadurch werden die Höhe und das Seitenverhältnis des Bildes gesetzt. Wie du weißt, ist ein <div> ein Blockelement, das immer 100% der Breite seines Elternelements einnimmt. Hier legen wir fest, dass seine Höhe 63% seiner Breite entsprechen soll.¹
  2. position: relative: Dadurch legen wir den Bezugspunkt fest, auf den sich die Positionsangaben der untergeordneten Bilder beziehen. Damit dies funktioniert, muss den Bildern die Anweisung position: absolute gegeben und die Position dann mit top, right, bottom und left bestimmt werden.
  3. overflow: hidden: Ganz wichtig! Jeglicher Inhalt, der aus dem Element herausragt, zum Beispiel weil die Bilder zu groß sind oder weil der Vorhang aus dem Bild hinaus geschoben wird, soll nicht sichtbar sein.
  4. cursor: pointer: Dadurch ändert sich der Mauszeiger, wenn er über das Bild fährt. Wir geben dem Anwender damit ein kleines, visuelles Feedback, dass das Bild angeklickt werden kann.

¹ Warum wir hierfür nicht height verwenden? Nun, das ist etwas kompliziert. Aus irgend einem Grund erlaubt CSS nur dann die Höhe eines Elements zu ändern, wenn man auch die Höhe aller seiner übergeordneten Elternelemente setzt. Also nur, wenn man bei <html> anfängt und allen untergeordneten Elementen bis zu dem Element, dessen Höhe man setzen will, eine explizite Höhe gibt, funktioniert die CSS-Anweisung height wie gewollt. Klingt komisch, ist aber so. 🐭

Die einzelnen Bilder werden mit position: absolute und den CSS-Anweisungen top, left, bottom und right in Position gebracht. 🐈🐶🐗🐒 Würde man dabei alle vier Elemente verwenden, könnte man genau die vier Eckpunkte festlegen. Hier machen wir es aber ein wenig anders: Wir legen nur einen der Eckpunkte fest und geben den Bildern zusätzlich eine Breite. Die passende Höhe berechnet der Browser dann ganz von alleine. Zum Beispiel so:

#theater > .rechts { position: absolute; top: 0; right: 0; width: 50%; }

Die Animationen entstehen dann durch folgende Anweisungen (hier am Beispiel des linken Vorhangs):

#theater > .links { position: absolute; left: 0; … transition: left 2s; } #theater > .links.offen { left: -50%; }

Die Anweisung transition: left 2s; sagt, dass jede Veränderung der Eigenschaft left als zwei Sekunden dauernde Animation abgespielt werden soll. Anfangs ist der Wert 0, da dies mit left: 0 so festgelegt wird. Um den Vorhang zu öffnen, muss ihm nur die CSS-Klasse offen hinzugefügt werden, wodurch sich der Wert auf -50% ändert, was der Browser entsprechend animiert. Umgekehrt muss die Klasse offen einfach wieder entfernt werden, um den Vorhang zu schließen, da der Wert dann auf 0 zurück geht.

JavaScript

Wenn du bis hierhin folgen konntest, ist dir sicher klar, warum der JavaScript-Code fast nichts mehr tun muss. Er muss eigentlich nur dafür sorgen, dass den beiden Vorhangbildern die Klasse offen gegeben wird, um den Vorhang zu öffnen und die Klasse wieder entfernt wird, um den Vorhang zu schließen. Als kleiner Bonus wird dann noch das Bühnenbild ausgetauscht und ein passendes Geräusch abgespielt. Fertig ist ein perfekter Theaterabend. 💐

Hangeln wir uns Stück für Stück durch den Quellcode und fangen mit den ersten sechs Zeilen an:

vorhangIstOffen = false; buehnenbilder = ["vorhang_buehne1.jpg", "…", "…"]; aktuellesBild = 0; applaus1 = new Audio("vorhang_auf.ogg"); applaus2 = new Audio("vorhang_zu.ogg");

Hierbei handelt es sich um globale Variablen² mit folgenden Werten:

  1. Ein Boolean, ob der Vorhang offen oder geschlossen ist
  2. Eine Liste mit drei Dateinamen für die einzelnen Hintergrundbilder
  3. Der Index des aktuell sichtbaren Hintergrundbilds, beginnend bei 0
  4. Zwei Objekte für die beiden Geräusche

² Globale Variablen sind im gesamten JavaScript-Code gültig. Das Gegenteil davon sind lokale Variablen, die nur innerhalb einer einzelnen Funktion (siehe unten) existieren.

Hm, sieht eigentlich ziemlich ähnlich zu Java aus, nur dass vor den Variablennamen nichts steht. Doch ab da wird es dann doch ein wenig anders:

function vorhangAufZu() { … }

Das ist eine Funktion, also dass, was man in Java eine Methode nennen würde. Dabei ist dir aber sicher schon aufgefallen, dass gar keine Klasse um die Funktion herum steht, und dass der Aufruf über das onclick-Attribut im HTML-Dokument erfolgt.

Die ersten drei Zeilen innerhalb der Funktion greifen auf das Document Object Model zu und besorgen sich jeweils eine Referenz auf das Bühnenbild, den linken Vorhang und den rechten Vorhang:

let buehne = document.querySelector("#theater > .buehne"); let vorhangLinks = document.querySelector("#theater > .links"); let vorhangRechts = document.querySelector("#theater > .rechts");

Die Syntax für den Parameter von document.querySelector() ist dabei dieselbe, die du auch von CSS her kennst. Das Ergebnis wird jeweils in eine lokale Variable gespeichert, was du am vorangestellten let erkennen kannst. Darauf folgt dann eine Prüfung, ob der Vorhang offen oder geschlossen ist:

if (!vorhangIstOffen) { // Der Vorhang ist geschlossen (beachte das Ausrufezeichen!) } else { // Der Vorhang ist offen }

In beiden Fällen passiert fast dasselbe. Zunächst wenn der Vorhang geschlossen ist:

if (!vorhangIstOffen) { // Merke dir, dass der Vorhang von nun an offen ist vorhangIstOffen = true; // Spiele des erste Applaus-Geräusch ab applaus1.currentTime = 0; applaus1.play(); // Füge den HTML-Elementen mit den Vorhangbildern die Klasse // (Attribut class) "offen" hinzu, um sie aus dem Bild zu schieben vorhangLinks.classList.add("offen"); vorhangRechts.classList.add("offen"); }

Und wenn er geschlossen ist:

else { // Merke dir, dass der Vorhang von nun an wieder zu ist vorhangIstOffen = false; // Spiele das zweite Applaus-Geräsuch ab applaus2.currentTime = 0; applaus2.play(); // Entfernte die Klasse "offen", um die Vorhänge wieder ins Bild // zu schieben vorhangLinks.classList.remove("offen"); vorhangRechts.classList.remove("offen"); // Erhöhe den Zähler mit dem aktuellen Hintergrundbild aktuellesBild++; if (aktuellesBild >= buehnenbilder.length) aktuellesBild = 0; // Setze einen Timer, der nach 2,1 Sekunden (also kurz nachdem // die Animation zu Ende gelaufen ist), das Bild wechselt window.setTimeout( () => buehne.src = buehnenbilder[aktuellesBild], 2100 ); }

Wie du siehst, ist das kein besonders komplizierter Quellcode. Lediglich der letzte Befehl hat es etwas in sich. Um ihn zu verstehen, musst du wissen, wie die Methode window.setTimeout() definiert ist:

window.setTimeout(funktion, milisekunden);

Sie bekommt im ersten Parameter eine Funktion übergeben, die nach Ablauf der festgestzten Zeit aufgerufen wird. Das funktioniert, weil Funktionen in JavaScript anders als in Java ganz normale Objekte sind, die man zum Beispiel in einer Variable ablegen oder eben auch einer anderen Funktion als Parameter übergeben kann. Und () => … ist in JavaScript die Schreibweise für eine anonyme Lambda-Funktion. Also eine Funktion ohne Namen. Etwas leserlicher hätten wir deshalb auch schreiben können:

function bildWechseln() { buehne.src = buehnenbilder[aktuellesBild]; } window.setTimeout(bildWechseln, 2100);

Oder, was man bis 2016 immer gesehen hat:

window.setTimeout(function() { buehne.src = buehnenbilder[aktuellesBild]; }, 2100);
