• CSS-Code kann innerhalb eines <style>-Elements stehen und wirkt immer auf die gesamte Seite.
  • Typischerweise stehen <style>-Elemente daher immer im <head> zusammen mit den anderen Metadaten der Seite.
  • Mit dem style-Attribut können allerdings auch CSS-Eigenschaften direkt am HTML-Element gesetzt werden.

    HTML und CSS können auf drei Weisen miteinander verknüpft werden, um die Stylingangaben zu aktivieren:

    • Durch Verweis auf eine externe Datei mit <link rel="stylesheet">
    • Als eingebettetes Stylesheet innerhalb eines <style>-Elements
    • Direkt an den HTML-Elementen mit dem style-Attribut.

    Alle drei Varianten sind auf dieser Seite dargestellt. Natürlich können sie auch beliebig kombiniert und prinzipiell auch mehrere, sich ergänzende Stylesheets verwendet werden.

    Trennen oder nicht trennen?

    Moderne Frameworks wie Bootstrap oder Tailwind CSS verzichten auf eine Trennung von HTML und CSS und nutzen stattdessen das class-Attribut von HTML, um seine Elemente zu stylen. Die Überlegung dahinter ist, dass Inhalt und Darstellung gerade bei komplexen UIs (und weniger bei einfachen Textdokumenten) eben doch sehr eng miteinander verbunden und nicht wirklich wiederverwendbar sind.

    Zumindest am Anfang wollen wir uns aber an die von der Web-Plattform vorgesehene Trennung von HTML und CSS halten und uns erst später mit möglichen Alternativen beschäftigen. HTML und CSS gehören für uns daher aktuell immer in getrennte Dateien.
