HTML wurde ursprünglich als Markupsprache für Textdokumente entwickelt, ohne Fokus auf die genaue Darstellung. Solange Überschriften und Absätze grob übereinstimmten, genügten die eingebauten Browser-Regeln. Diese erfüllen jedoch kaum noch die Anforderungen moderner Webanwendungen. CSS ermöglicht es uns daher, die vordefinierten Browser-Stile zu überschreiben und eigene Regeln festzulegen, auf diese Weise ansprechende Layouts zu gestalten.

Voraussetzung dafür ist allerdings eine gut strukturierte HTML-Datei. Das hier gezeigte Beispiel zeigt, wie es geht. Hierfür stellen wir uns vor, die Webseite einer Klavierschule zu bauen. Diese soll aus einem Kopfbereich mit dem Namen der Schule und Navigationsmenü, einem Hauptbereich mit einer Überschrift und ein paar Bildern sowie einem Abspann mit den Pflichtangaben bestehen. Diese Struktur müssen wir versuchen, möglichst einfach in HTML zu definieren, wobei wir hier von oben nach unten und links nach rechts vorgehen können:

<header> <h2>Faszination Klavier</h2> <nav> … </nav> </header> <main> … </main> <footer> … </footer>

Im hier gezeigten Beispiel wurde dabei großer Wert auf semantischen Markup-Code gelegt, was bedeutet, dass die verwendeten HTML-Elemente die Intention der Darstellung möglichst gut beschreiben. Dies macht den Quellcode leserlicher und hilft auch assistiven Technologien wie Screenreadern, die Seitenstruktur besser zu verstehen.

Dies bildet die Grundlage für das Stylesheet, indem die Elemente im nächsten Schritt ausgewählt und mit Darstellungsoptionen versehen werden können. Ohne Stylesheet sieht die Seite natürlich sehr unfertig aus und entspricht überhaupt nicht dem gewünschten Ergebnis. Mit einfachen Regeln wie den folgenden, kann dies aber leicht geändert werden.

html, body { margin: 0; padding: 0; } header, footer { background-color: #0A0A0A; border-style: solid; border-color: black; border-width: 0; border-bottom-width: 2px; padding: 0.5em; color: white; font-size: 95%; }

Dabei zeigt sich auch schon die Syntax von CSS. Ein Stylesheet besteht immer aus einem oder mehreren, durch geschweifte Klammern eingeschlossenen Blöcken. Vor den Klammern steht ein so genannter Selektor zur Auswahl der gewünschten HTML-Elemente. Innerhalb der Klammern stehen Name-Wert-Paare zur Definition ihrer Eigenschaften. Diese werden immer in der Form name: wert; geschrieben.

Aktiv wird das Stylesheet allerdings erst, wenn es mit der HTML-Datei verknüpft wird, wofür ein Verweis auf die CSS-Datei in den HTML-Code eingebaut werden muss. Dies erfolgt mit folgenden Zeilen im Kopfteil der Seite:

<head> … <link rel="stylesheet" href="style.css" /> </head>

Wenn alles gut geht, sieht das Ergebnis dann wie hier gezeigt aus. Falls nicht, sind Ausprobieren und Experimentieren der Schlüssel zum Erfolg.
