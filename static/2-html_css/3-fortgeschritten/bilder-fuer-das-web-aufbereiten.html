Bilder sind für viele Webseiten unverzichtbar. Egal ob als Hintergrundbild, als lustiges Katzenbild oder als echt seriöse Abbildung: Bilder gehören einfach dazu. Falsch eingesetzt können sie aber auch einer der Hauptgründe für lange Ladezeiten und frustrierte Besucher sein. Denn im Web gilt, dass eine Seite so schnell wie nur irgend möglich laden sollte, damit der Besucher nicht das Interesse verliert und einfach weiter surft. Dabei sollten Sie auch beachten, dass viele Besucher inzwischen viel mit dem Smartphone unterwegs sind und das Problem dann noch viel größer ist. Denn mobile Geräte haben oft nur eine schlechte Internetverbindung und lange Ladezeiten sind der Tod eines jeden Akkus. 😒

Aus diesem Grund gilt für Grafiken im Web im wahrsten Sinne „weniger ist mehr“. Sowohl mit Blick auf die Anzahl als auch ihre Dateigröße. Welche Bilder auf Ihrer Seite verzichtbar sind, lässt sich pauschal nicht beantworten. Nachfolgend finden Sie aber ein paar Tipps, wie Sie wenigstens die Dateigröße klein halten können.

Wählen Sie das richtige Dateiformat

Noch bevor Sie eine Grafik erstellen, sollten Sie sich Gedanken darüber machen, was sie darstellen soll und welches Dateiformat dafür infrage kommt. Denn mit dieser einfachen Entscheidung können Sie bereits die größten Einsparungen erzielen oder eben auch den meisten Platz verschwenden. Zwischen folgenden Formaten können Sie dabei wählen:

PNG (Portable Network Graphics)

PNG ist sozusagen das Standardformat für Abbildungen im Web und ein moderner Nachfolger für das alte GIF-Format. Wie bei den meisten Formaten handelt es sich um ein sogenanntes Rastergrafikformat, was bedeutet, dass die Bilder Pixel für Pixel gespeichert werden. Vorteile des Formats sind:

  • Verlustfreie Komprimierung der Bilder¹
  • Unterstützung jeder beliebigen Farbtiefe ohne Farbrasterung²
  • Unterstützung eines Alphakanals für halbdurchsichtige Pixel³

Allerdings ist das Format nicht für alle Arten von Bildern geeignet. Insbesondere fotoähnliche Bilder mit vielen Farben führen zu sehr großen Dateien. Am besten eignet es sich daher für Screenshots, bei denen es auf die Lesbarkeit der Schrift ankommt, sowie für Bilder mit wenigen Farben oder mit halbdurchsichtigem Hintergrund.

¹ Durch die Komprimierung gehen keine Bildinformationen verloren.

² Es wird keine Farbrasterung benötigt, um die Anzahl der Farben zu reduzieren. Andere Formate arbeiten hier mit einer sogenannten Farbpalette und können nur eine bestimmte Anzahl Farben gleichzeitig darstellen, meist nur 256 Stück.

³ Zu jedem Pixel wird zusätzlich noch ein Prozentwert gespeichert, wie durchsichtig oder deckend er dargestellt wird.

GIF (Graphics Interchange Format)
Das GIF-Format wurde bereits 1988 noch vor dem Web erfunden. Lange Zeit galt es als das Standardformat für den Austausch von Bildern zwischen Computerbenutzern. Im Vergleich zu PNG hat es aber die Nachteile, dass es nur 256 Farben speichern kann und dass keine halbtransparenten Pixel unterstützt werden. GIF-Grafiken mit durchsichtigem Hintergrund haben daher so gut wie immer unschöne Kanten. Allerdings kann man damit einfache Animationen erstellen, was mit PNG nicht möglich ist.

JPEG (Joint Photographic Experts Group)

Dies ist das bekannte Standardformat für komprimierte Fotos, das von jeder beliebigen Digitalkamera erzeugt wird. Im Vergleich zu PNG sind die Dateien sehr viel kleiner, die Komprimierung ist dafür aber verlustbehaftet. Durchsichtige Hintergründe sind ebenfalls nicht möglich. JPEG sollte daher das Standardformat sein, wenn Sie Fotos oder sehr bunte Screenshots einbinden möchten.

Bei Fotos mit weichen Kanten fallen die Kompressionsverluste oft nicht auf, bei harten Kanten und bei Schriftzeichen dafür umso mehr. Zu stark komprimierte Bilder beinhalten gut sichtbare „Blöckchen“ mit verzerrten Farben, und in der Nähe von Buchstaben und Wörtern finden sich häufig rauschende Streupixel.

SVG (Scalable Vector Graphics)

SVG ist ein XML-basiertes Format für skalierbare Vektorgrafiken (sagt ja schon der Name 🙃). Anstelle einzelner Pixel werden nur Anweisungen gespeichert, anhand derer sich eine Zeichnung rekonstruieren lässt. SVG-Grafiken sehen daher in jeder Größe und Auflösung gestochen scharf aus. Das Format eignet sich daher gut für Schaubilder und andere technische Zeichnungen. Richtig angewendet, können aber auch ansprechende Zierelemente damit gestaltet werden. Des Weiteren hat es noch folgende Vorteile:

  • SVG-Befehle können über das <svg>-Tag direkt in HTML eingebunden werden.
  • Einzelne Elemente einer SVG-Grafik können mit CSS formatiert werden. Man kann damit z.B. die Farbe oder Art einer Linie nachträglich zur Laufzeit ändern.
  • Zusätzlich können die Elemente einer SVG-Grafik auch mit JavaScript angesprochen und manipuliert werden. Man kann also ohne weiteres auch interaktive Grafiken erstellen, die zum Beispiel auf Maus- oder Touchgesten reagieren.

So klein wie möglich, so groß wie nötig

Dies ist eine sehr wichtige Regel für Rastergrafiken im Web. Moderne Kameras erzeugen oft extrem große Bilder mit einer sehr hohen Auflösung. Damit eignen sich die Bilder gut für den Druck oder eine Vollbildanzeige auf großen Bildschirmen. Für Webseiten sind sie aber viel zu groß! Bevor Sie also ein Foto in Ihre Seite einbinden, sollten Sie es unbedingt verkleinern. Für die genaue Größe gibt es keine magischen Werte, die immer funktionieren. Letztlich müssen Sie einfach versuchen, einen Mittelweg zwischen kleiner Dateigröße und guter Darstellung zu finden. Folgende Zahlen können Ihnen dabei als Hilfe dienen:

  • Kleine Bilder: ca. 500 Pixel hoch oder breit, ca. 50 kB
  • Mittlere Bilder: ca. 800 bis 1000 Pixel hoch oder breit, ca. 120 kB
  • Große Bilder: ca. 1000 bis 1500 Pixel hoch oder breit, ca. 250 kB

Diese Werte sind sicher sehr konservativ geschätzt und Sie werden sie nicht immer einhalten können. Und je mehr die Bildschirmauflösungen und Internetbandbreiten im Laufe der Zeit zunehmen, desto größer können die Zahlen werden. Dennoch sollten Sie wirklich um jeden Preis versuchen, jedes unnötige kB einzusparen. Denn es gibt immer einen Anwender, der gerade im tiefsten Urwald (oder im kanadischen Hinterland!) sitzt und über eine instabile und mega-langsame Funkverbindung surft, die ständig zusammenbricht (haben wir in Kanada wirklich erlebt). Deshalb sollten Sie die Anzahl der Pixel immer klein halten, auch wenn die meisten Bildschirme und Mobilgeräte inzwischen Full HD und mehr darstellen können.

Ein weiterer Trick aus dieser Rubrik ist die Verwendung unterschiedlicher Bilder für unterschiedliche Endgeräte. Dies können Sie entweder mit CSS Media Queries oder mit dem (noch nicht von allen Browsern unterstützten) <picture>-Tag erreichen. Kleinen Geräten mit in der Regel wenig Bandbreite können Sie damit kleinere Bilder senden als größeren Geräten mit großen Bildschirmen und meist üppigem Internetanschluss.

Optimieren Sie die Exportparameter

Was uns nun endlich zum Screenshot auf dieser Seite bringt: Gute Grafikprogramme wie The Gimp erlauben es, das Dateiformat beim Speichern bzw. Exportieren eines Bildes nochmal zu tunen, um kostbare kB zu sparen. Teilweise kann sich die Größe einer Datei dadurch um die Hälfte reduzieren. Der Screenshot zeigt daher eine gute Voreinstellung, die Sie als Grundlage für eigene JPEG-Bilder verwenden können:

  • Show preview in image window: Wenn dieses Häkchen gesetzt ist, sehen Sie im Exportfenster eine Berechnung der erzielten Dateigröße. Gleichzeitig können Sie das Ergebnis im Hauptfenster von GIMP kontrollieren, da dort eine exakte Vorschau angezeigt wird, wie die komprimierte Grafik später aussehen wird. Achten Sie deshalb besonders auf Kompressionsartefakte und entscheiden Sie, ob Sie mit ihnen leben können (ohne geht nicht) oder ob Sie doch lieber ein paar mehr Bytes spendieren wollen.
  • Quality: Das ist der wichtigste Parameter. Je niedriger der Wert, desto kleiner die Datei und desto schlechter die Bildqualität. Je nach Grafik kann man auch mal bis 50% oder tiefer gehen, meistens benötigt man dann aber doch so um die 60% bis 80%, damit es noch gut aussieht.
  • Subsampling: 4:2:2 Hierdurch wird die Farbtiefe reduziert, was meistens wenn überhaupt nur auf den zweiten Blick auffällt. Jedoch kann damit in der Regel rund ein Drittel der Dateigröße eingespart werden.
  • Optimize und Progressive: Drücken die Dateigröße nochmals um ein paar kB. Die Auswirkung ist nicht so groß, aber es kommt ja bekanntlich auf jedes Byte an.
  • Save EXIF-Data, Save thumbnail, Save XMP data, Comment: Das sind alles unnötige Zusatzdaten, die der Browser nicht darstellen kann, die aber Platz belegen. Diese Häkchen sollten Sie für Webgrafiken immer ausschalten.
