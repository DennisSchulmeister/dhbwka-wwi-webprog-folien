Erstellen Sie eine minimale Webseite über sich als digitale Visitenkarte im Web, sodass jemand nur die URL aufrufen muss, um auf einen Blick das Wichtigste über Sie zu erfahren. Ein Beispiel, wie so eine Seite aussehen könnte, sehen Sie unten. Folgende Merkmale sollte die Seite aufweisen:

  • Inhalt horizontal und vertikal im Browserfenster zentriert
  • Ein Foto in voller Breite über oder voller Höhe neben dem Inhalt
  • Margin und Padding nur für den Textbereich, nicht für das Foto
  • Gezielter Einsatz von Farbe und ein paar HTML-Elementen wie <h1> oder <b>
  • Insgesamt ein einfaches aber ansprechendes Design

Für den zentrierten Hauptbereich wurde in der Musterlösung ein einzelnes HTML-Element in einer Flexbox platziert. Da die gesamte Seite nur aus einem zentrierten Element besteht, wurde als Flexbox-Container einfach der <body> verwendet:

body { display: flex; /* Inhalte mit dem Flexbox-Algorithmus anordnen */ justify-content: center; /* Inhalte entlang der Hauptachse zentrieren */ align-items: center; /* Inhalte entlang der Nebenachse zentrieren */ min-height: 100vh; /* Body mindestens so hoch wie der Viewport */ } html, body { /* Unschöne Scrollbalken vermeiden */ margin: 0; padding: 0; }

Die eigentlichen Seiteninhalte müssen dann nur noch in ein Elternelement wie zum Beispiel ein <main> oder ein <div> verschoben werden:

<body> <main> Hier steht der eigentliche Inhalt. Da der Body eine Flexbox ist, wird dieses Element automatisch horizontal und vertikal zentriert. </main> </body>

In seiner Voreinstellung sorgt der Flexbox-Algorithmus dafür, dass die direkten Kinder eines HTML-Elements (hier des <body>) nebeneinander angeordnet werden. Die Hauptachse ist daher die X-Achse und die Nebenachse die Y-Achse. Würde man dem <body> noch ein zweites Kindelement zuweisen, stünde dieses daher neben dem bisherigen Inhalt. Mit gap: 1em könnte dann ein kleiner Abstand zwischen den Elementen vorgesehen werden, wenn diese nicht aneinander kleben sollen. Mit der CSS-Anweisung flex-direction: row könnten hingegen die beiden Achsen vertauscht werden, um eine Anordnung untereinander zu erhalten.

Das Rücksetzen von Margin und Padding für <html> und <body> ist dabei notwendig, weil diese standardmäßig tatsächlich Margins und Paddings besitzen, die auf ihre Größe hinzugerechnet werden. Dadurch hätte man in Kombination mit dem min-height: 100vh unschöne Scrollbalken, mit denen die Seite tatsächlich ein klein wenig hin und her gescrollt werden könnte.

Für den unscharfen Hintergrund in der Musterlösung wurde zunächst dasselbe Foto wie im Hauptbereich als gestrecktes Hintergrundbild für die gesamte Seite festgelegt:

html { background-image: url(foto.jpg); background-size: cover; background-attachment: fixed; }

Die Unschärfe entsteht durch ein Dummy-Element ohne Inhalt:

<body> <!-- Dummy-Element zum Weichzeichnen des Hintergrunds --> <div id="bg-blur"></div> <!-- Seiteninhalt --> <main> Inhalt des Hauptbereichs </main> </body>

Das Dummy-Element wird mit absoluter Positionierung über den gesamten Viewport (Anzeigebereich des Browser-Fensters) gelegt und mit einem „Backdrop Filter” zum Weichzeichnen des durchscheinenden Hintergrunds belegt:

#bg-blur { position: absolute; /* Das Element absolut mit Bezug zum Viewport platzieren */ top: 0; /* Kein Abstand zur oberen Kante des Viewports */ bottom: 0; /* Kein Abstand zur unteren Kante des Viewports */ left: 0; /* Kein Abstand zur linken Kante des Viewports */ right: 0; /* Kein Abstand zur rechten Kante des Viewports */ z-index: -100; /* Dummy-Element darf den Seiteninhalt nicht überlagern! */ backdrop-filter: blur(15px); /* Alles, was hinter dem Element liegt, weichzeichnen */ }

Das Geheimnis ist hier also die Kombination aus position: absolute und backdrop-filter: blur(15px). Die Anweisung z-index: -100 wird zusätzlich benötigt, damit der eigentliche Seiteninhalt in der dreidimensionalen Z-Achse über dem Dummy-Element liegt und somit weiterhin lesbar bleibt. Ohne diese Anweisung sähe alles so aus, als hätte man seine Brille vergessen. 🥸
