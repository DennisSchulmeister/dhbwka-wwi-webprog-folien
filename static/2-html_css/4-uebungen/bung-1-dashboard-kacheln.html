HTML wurde zwar zum Schreiben wissenschaftlicher Aufsätze und ähnlicher Dokumente erfunden, kann tatsächlich aber für alle Arten von Bildschirminhalten verwendet werden. Schon bald richtete sich die Aufmerksamkeit daher auf die Beschreibung komplexer UI-Layouts mit HTML und CSS. Wurden diese zunächst noch „traditionell“ per URL im Browser aufgerufen, können heute sogar Mobile Apps, Desktop-Anwendungen und mehr mit den Webtechnologien erstellt werden. In dieser Aufgabe wollen wir daher ein kleines Dashboard für eine fiktive Aufgaben-App bauen.

Bespreche die folgenden Fragen zu HTML und CSS mit deine*r Sitznachbar*in oder dem freundlichen KI-Chatbot von nebenan. Versucht anschließend, die Kernaussagen in eigenen Worten zusammenzufassen.
