Als am 22. Dezember 2014 der legendäre Sänger Joe Cocker starb, zeigte die offizielle Webseite www.cocker.com eine einfache Gedenkseite mit den Lebensdaten und den Covern aller bis dato veröffentlichten Alben. Inzwischen findet sich auf der Seite natürlich ganz anderer Inhalt, weshalb die Seite von damals in dieser Aufgabe rekonstruiert werden soll.

Das Grundgerüst der Seite wurde bereits fertiggestellt. Jedoch müssen noch verschiedene Anpassungen vorgenommen werden, um das gewünschte Layout zu realisieren. Die notwendigen Änderungen sind als Kommentar in der Datei index.html beschrieben.

Hier haben wir eine Knobelaufgabe für dich. Die zu erstellende Webseite ist nicht groß. Aber es gibt mehrere Wege, wie das gewünschte Layout erzielt werden kann. Klassisch mit flex: right, als Tabelle (nicht so toll), als Flexbox oder CSS Grid. Was darf es sein? 🙃
