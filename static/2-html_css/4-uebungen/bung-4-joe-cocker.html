Als am 22. Dezember 2014 der legendäre Sänger Joe Cocker starb, zeigte die offizielle Webseite www.cocker.com eine einfache Gedenkseite mit den Lebensdaten und den Covern aller bis dahin veröffentlichten Alben. Inzwischen findet sich auf der Seite natürlich ganz anderer Inhalt, weshalb die Seite von damals in dieser Aufgabe rekonstruiert werden soll.

Das Grundgerüst der Seite wurde bereits fertiggestellt. Allerdings müssen noch verschiedene Anpassungen vorgenommen werden, um das gewünschte Layout zu realisieren. Die notwendigen Änderungen sind als Kommentar in der Datei index.html beschrieben.

Diese Aufgabe stellt eine Herausforderung dar. Die zu erstellende Webseite ist nicht umfangreich, aber es gibt mehrere Möglichkeiten, das gewünschte Layout umzusetzen: Klassisch mit float: right, als Tabelle (nicht empfehlenswert), als Flexbox oder CSS Grid.
