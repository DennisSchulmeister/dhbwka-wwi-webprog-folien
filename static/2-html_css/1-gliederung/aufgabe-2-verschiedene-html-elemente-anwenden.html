Legen Sie eine neue HTML-Datei an und probieren Sie die gelernten HTML-Tags aus:

  1. Definieren Sie mehrere Absätze mit Überschriften und Unterüberschriften.
  2. Verwenden Sie mindestens eine geordnete oder ungeordnete Aufzählungsliste.
  3. Bauen Sie ein oder zwei Bilder in die Seite ein. Achten Sie darauf, dass sie nicht zu groß sind!
  4. Fügen Sie der Seite einen Link auf einen Wikipedia-Artikel Ihrer Wahl hinzu.
