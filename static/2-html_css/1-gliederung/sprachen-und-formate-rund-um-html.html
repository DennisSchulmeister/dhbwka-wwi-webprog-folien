    Dass die Beispiele am Anfang des Kapitels nur auf HTML basieren, ist nicht ganz richtig. Denn streng genommen handelt es sich bei HTML nur um eine Sprache zur Strukturierung der Inhalte. Zwar werden der grundlegende Aufbau einer Seite sowie alle darin enthaltenen Informationen in HTML definiert, ohne ein paar Freunde geht es dann aber doch nicht. 😎

    Jede HTML-Webanwendung besteht daher aus einer Kombination der folgenden Programmiersprachen, die Hand in Hand zusammenspielen:

    HTML (HyperText Markup Language)
    Mit HTML werden die darzustellenden Inhalte definiert und die „Bereiche“ einer Seite festgelegt. Hierfür werden in einer HTML-Datei alle Textinhalte wie Überschriften, Absätze oder Abbildungen festgelegt und mit Namen versehen, um sie später zum Beispiel als Kopfbereich oder Sidebar darstellen zu können.
    CSS (Cascading StyleSheets)

    Das Aussehen der HTML-Inhalte wird in einem sogenannten Stylesheet definiert. Dadurch werden Inhalt und Aussehen getrennt, sodass ein einmal erstelltes Layout für mehrere HTML-Dateien verwendet oder leicht ausgetauscht werden kann.¹ Hier kommen dann die Namen ins Spiel, die den einzelnen Elementen in den HTML-Dateien gegeben wurden, um ihr Aussehen zu definieren.

    ¹ Beispielsweise, um zwei HTML-Dateien dasselbe Layout zu geben. Oder um an Weihnachten seiner Webseite ein anderes Layout zu geben, ohne alle HTMLs anpassen zu müssen. 🎅 🎄

    SVG (Scalable Vector Graphics)
    SVG ist eines der verschiedenen Grafikformate im Web. Das Besondere daran ist, dass es sich um ein Vektorformat (statt einem Rasterformat) handelt, das mit CSS und JavaScript darüber hinaus auch komplett skriptbar ist. Somit lassen sich über HTML hinaus zum Beispiel interaktive Schaubilder und andere grafische Elemente erstellen.
    JavaScript
    Die Schaltzentrale, die allen Webanwendungen ihre clientseitige Logik gibt, ist JavaScript. Einzelheiten dazu werden Sie später noch erfahren. Hier reicht es erst mal zu wissen, dass es sich um eine vollwertige Programmiersprache handelt, die eingebettet in einer Webseite im Browser läuft und alle Inhalte der Seite ändern kann. Zusammen mit ihrer umfangreichen Programmierschnittstelle (API) zur App-Entwicklung lassen sich damit fast beliebige Anwendungen entwickeln.
