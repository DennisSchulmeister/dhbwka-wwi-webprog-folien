Führen Sie die folgenden Schritte zur Erstellung einer einfachen Webseite aus:

  1. Kopieren Sie den Quellcode der vorherigen Seite in einen Texteditor Ihrer Wahl.
  2. Speichern Sie die Datei mit der Endung .html ab und öffnen Sie sie im Browser.
  3. Ändern Sie ein paar Inhalte in der Datei und schauen Sie sich das Ergebnis an.
  4. Legen Sie eine zweite HTML-Datei an und bauen Sie jeweils einen Link von der einen auf die andere ein.
Achten Sie auf den richtigen Zeichensatz der Datei. Das Tag <meta charset="utf-8" /> weist den Browser an, die Datei als UTF-8-Datei zu lesen. Sonst werden die Umlaute und Sonderzeichen nicht richtig dargestellt.
Quellcode im Editor Darstellung im Browser
