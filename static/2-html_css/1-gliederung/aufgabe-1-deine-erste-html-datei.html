Führe die folgenden Schritte zur Erstellung einer einfachen Webseite aus:

  1. Kopiere den Quellcode der vorherigen Seite in einen Texteditor deiner Wahl.
  2. Speichere die Datei mit der Endung .html ab und öffne sie im Browser.
  3. Ändere ein paar Inhalte in der Datei und schaue dir das Ergebnis an.
  4. Lege eine zweite HTML-Datei an und baue jeweils einen Link von der einen auf die andere ein.
Achte auf den richtigen Zeichensatz der Datei. Das Tag <meta charset="utf-8" /> weist den Browser an, die Datei als UTF-8-Datei zu lesen. Sonst werden die Umlaute und Sonderzeichen nicht richtig dargestellt.
Quellcode im Editor Darstellung im Browser

Um zu verstehen, wie einfach HTML funktioniert, sollst du hier eine einfache HTML-Datei anlegen und im Browser öffnen. Du kannst hierfür eine beliebige IDE („Integrated Development Environment“ bzw. „Integrierte Entwicklungsumgebung“) verwenden. Falls du noch keine IDE verwendest, ist Visual Studio Code eine gute Wahl. 🚀

Bildnachweis: Atom Webseite

Stelle sicher, dass du die Datei mit der Endung .html und im UTF-8-Format speicherst.
