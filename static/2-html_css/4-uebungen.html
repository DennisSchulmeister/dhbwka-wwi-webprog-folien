Erstelle eine minimale Webseite über dich als deine Visitenkarte im Web. So, dass jemand nur die URL aufrufen muss, um auf einen Blick das Wichtigste über dich zu erfahren. Ein Beispiel, wie so eine Seite aussehen könnte, siehst du unten. Folgende Merkmale sollte die Seite aufweisen:

  • Inhalt horizontal und vertikal im Browserfenster zentriert
  • Ein Foto in voller Breite über oder voller Höhe neben dem Inhalt
  • Margin und Padding nur für den Textbereich, nicht für das Foto
  • Gezielter Einsatz von Farbe und ein paar HTML-Elementen wie <h1> oder <b>
  • Insgesamt ein einfaches aber ansprechendes Design

Für den zentrierten Hauptbereich wurde in der Musterlösung ein einzelnes HTML-Element in einer Flexbox platziert. Da die gesamte Seite nur aus einem zentrierten Element besteht, wurde als Flexbox-Container einfach der <body> verwendet:

body { display: flex; /* Inhalte mit dem Flexbox-Algorithmus anordnen */ justify-content: center; /* Inhalte entlang der Hauptachse zentrieren */ align-items: center; /* Inhalte entlant der Nebenachse zentrieren */ min-height: 100vh; /* Body mindestens so hoch wie der Viewport */ } html, body { /* Unschöne Scrollbalken vermeiden */ margin: 0; padding: 0; }

Die eigentlichen Seiteninhalte müssen dann nur noch in ein Eltern-Element wie zum Beispiel ein <main> oder ein <div> verschoben werden:

<body> <main> Hier steht der eigentliche Inhalt. Da der Body eine Flexbox ist, wird dieses Element automatisch horizontal und vertikal zentriert. </main> </body>

In seiner Voreinstellung sorgt der Flexbox-Algorithmus dafür, dass die direkten Kinder eines HTML-Elements (hier des <body>) nebeneinander angeordnet werden. Die Hauptachse ist daher die X-Achse und die Nebenachse die Y-Achse. Würde man dem <body> noch ein zweites Kind-Element zuweisen, stünde dieses daher neben dem bisherigen Inhalt. Mit gap: 1em könnte dann ein kleiner Abstand zwischen den Elementen vorgesehen werden, wenn diese nicht aneinander kleben sollen. Mit der CSS-Anweisung flex-direction: row könnten hingegen die beiden Achsen vertauscht werden, um eine Anordnung untereinander zu erhalten.

Das Rücksetzen von Margin und Padding für <html> und <body> ist dabei notwendig, weil diese standardmäßig tatsächlich Margins und Paddings besitzen, die auf ihre Größe hinzugerechnet werden. Dadruch hätte man in Kombination mit dem min-height: 100vh unschöne Scrollbalken, mit denen die Seite tatsächlich in klein wenig hin und her gescrollt werden könnte.

Für den Unscharfen Hintergrund in der Musterlösung wurde zunächst dasselbe Foto wie im Hauptbereich als gestrecktes Hintergrundbild für die gesamte Seite festgelegt:

html { background-image: url(foto.jpg); background-size: cover; background-attachment: fixed; }

Die Unschräfe entsteht durch ein Dummy-Element ohne Inhalt:

<body> <!-- Dummy-Element zum Weichzeichnen des Hintergrunds --> <div id="bg-blur"></div> <!-- Seiteninhalt --> <main> Inhalt des Hauptbereichs </main> </body>

Das Dummy-Element wird mit absoluter Positionierung über den gesamten Viewport (Anzeigebereich des Browser-Fensters) gelegt und mit einem „Backdrop Filter” zum Weichzeichnen des durchscheinenden Hintergrunds belegt:

#bg-blur { position: absolute; /* Das Element absolut mit Bezug zumkViewport platzieren */ top: 0; /* Kein Abstand zu oberen Kante des Viewports */ bottom: 0; /* Kein Abstand zur unteren Kante des Viewports */ left: 0; /* Kein Abstand zu linken Kante des Viewports */ right: 0; /* Kein Abstand zur rechten Kante des Viewports */ z-index: -100; /* Dummy-Element darf den Seiteninhalt nicht überlagern! */ backdrop-filter: blur(15px); /* Alles, was hinter dem Element liegt, weichzeichnen */ }

Das Geheimnis ist hier also die Kombination aus position: absolute und backdrop-filter: blur(15px). Die Anweisung z-index: -100 wird zusätzlich benötigt, damit der eigentliche Seiteninhalt in der drei-dimensionalen Z-Achse über dem Dummy-Element liegt und somit weiterhin lesbar bleibt. Ohne diese Anweisung sähe alles so aus, als hätte man seine Brille vergessen. 🥸

Außerdem enthält sie noch viel mehr Inhalt, den nachzubauen sich nicht lohnt. Flexbox, Flexbox, Flexbox. Am einfachsten lässt sich das Layout mit mehreren, ineinander geschachtelten Flexboxen realisieren. Die Einteilung der Seite selbst, die Menüzeile, die Suchzeile, die Textbereiche und der Fußbereich: Sie alle sind Flexboxen mit unterschiedlichen Einstellungen. Vor Beginn der Aufgabe lohnt es sich daher, die Beschreibung des Flexbox-Algorithmus auf css-tricks.com zu studieren und immer wieder zu konsultieren.

Denke zuerst vertikal, dann horizontal. Versuche also erst die übereinander gestapelten Bereiche zu definieren und mit dem Flexbox-Algorithmus zu positionieren. Das Elternelement muss hierfür die CSS-Anweisungen display: flex und flex-direction: column sowie weitere Anweisungen zur Ausrichtung ihrer Inhalte besitzen. Anschließend mache die Bereiche selbst zu Flexboxen und definiere damit die horizontale Ausrichtung ihrer Inhalte.

Ein guter Trick für die bunten Farbstreifen oben und unten ist, einfach dem <html>-Element einen Farberlauf zu geben und die Dicke der Streifen als Padding zu definieren. Damit der Hauptinhalt den Farbverlauf überdeckt, müssen zusätzlich der Flexbox-Algorithmus aktiviert und für das <body>-Element eine Hintergrundfarbe gesetzt werden:

html { background: rgb(221,145,17); background: linear-gradient( 90deg, rgba(221,145,17,1) 0%, rgba(255,9,28,1) 45%, rgba(250,0,255,1) 100% ); min-height: 100%; padding-top: 0.6em; padding-bottom: 0.6em; box-sizing: border-box; display: flex; flex-direction: column; } body { flex-grow: 1; }

Um die CSS-Anweisungen für Farbverläufe zu generieren, gibt es diverse Onlinetools wie https://cssgradient.io. Damit wurde auch der eben beschriebene Farbverlauf erzeugt, welcher der Vorlage recht nahe kommen sollte.

Als Hintergrundbild für das Jumbotron (großer bunter Bereich mit dem Eye-Catcher-Text) kann das in der Vorlage enthaltene Bild jumbotron-hintergrund.png verwendet werden. Die Farbgebung ist ähnlich wie im Original. Allerdings handelt es sich um ein frei verfügbares Bild (Quelle), dessen Verwendung keine Urheberrechte verletzt. 🐒
