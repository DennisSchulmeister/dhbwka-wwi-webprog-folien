HTML wurde ursprünglich als Markupsprache für Textdokumente entwickelt, ohne Fokus auf die genaue Darstellung. Solange Überschriften und Absätze grob übereinstimmten, genügten die eingebauten Browser-Regeln. Diese erfüllen jedoch kaum noch die Anforderungen moderner Webanwendungen. CSS ermöglicht es uns daher, die vordefinierten Browser-Stile zu überschreiben und eigene Regeln festzulegen, auf diese Weise ansprechende Layouts zu gestalten.

Voraussetzung dafür ist allerdings eine gut strukturierte HTML-Datei. Das hier gezeigte Beispiel zeigt, wie es geht. Hierfür stellen wir uns vor, die Webseite einer Klavierschule zu bauen. Diese soll aus einem Kopfbereich mit dem Namen der Schule und Navigationsmenü, einem Hauptbereich mit einer Überschrift und ein paar Bildern sowie einem Abspann mit den Pflichtangaben und bestehen. Diese Struktur müssen wir versuchen, möglichst einfach in HTML zu definieren, wobei wir hier von oben nach unten und links nach rechts vorgehen können:

<header> <h2>Faszination Klavier</h2> <nav> … </nav> </header> <main> … </main> <footer> … </footer>

Im hier gezeigten Beispiel wurde dabei großer Wert semantischen Markup-Code gelegt, was bedeutet, dass die verwendeten HTML-Elemente die Intention der Darstellung möglichst gut beschreiben. Dies macht den Quellcode leserlicher und hilft auch assistiven Technologien wie Screenreadern, die Seitenstruktur besser zu verstehen.

Dies bildet die Grundlage für das Stylesheet, indem die Elemente im nächsten Schritt ausgewählt und mit Darstellungsoptionen versehen werden können. Ohne Stylesheet sieht die Seite natürlich sehr unfertig und überhaupt nicht wie gewünscht ist. Mit einfachen Regeln wie den folgenden, kann dies aber leicht geändert werden.

html, body { margin: 0; padding: 0; } header, footer { background-color: #0A0A0A; border-style: solid; border-color: black; border-width: 0; border-bottom-width: 2px; padding: 0.5em; color: white; font-size: 95%; }

Dabei zeigt sich auch schon die Syntax von CSS. Ein Stylesheet besteht immer aus einem oder mehreren, durch geschweifte Klammern eingeschlossene Blöcke. Vor den Klammern steht ein so genannter Selektor zur Auswahl der gewünschten HTML-Elemente. Innerhalb der Klammern stehen Name-Wert-Paare zur Definition ihrer Eigenschaften. Diese werden immer in der Form name: wert; geschrieben.

Aktiv wird das Stylesheet allerdings erst, wenn es mit der HTML-Datei verknüpft wird, wofür ein Verweis auf die CSS-Datei in den HTML-Code eingebaut werden muss. Dies erfolgt mit folgenden Zeilen im Kopfteil der Seite:

<head> … <link rel="stylesheet" href="style.css" /> </head>

Wenn alles gut geht, sieht das Ergebnis dann wie hier gezeigt aus. Wenn nicht: Probieren, probieren, probieren. 🙃

    HTML und CSS können auf drei Weisen miteinander verknüpft werden, um die Stylingangaben zu aktivieren:

    • Durch Verweis auf eine externe Datei mit <link rel="stylesheet">
    • Als eingebettetes Stylesheet innerhalb eines <style>-Elements
    • Direkt an den HTML-Elementen mit dem style-Attribut.

    Alle drei Varianten sind auf dieser Seite dargestellt. Natürlich können sie auch beliebig kombiniert und prinzipiell auch mehrere, sich ergänzende Stylesheets verwendet werden.

    Trennen oder nicht trennen?

    Moderne Frameworks Bootstrap oder Tailwind CSS verzichten auf eine Trennung von HTML und CSS und nutzen stattdessen das class-Attribut von HTML, um seine Elemente zu stylen. Die Überlegung dahinter ist, dass Inhalt und Darstellung gerade bei komplexen UIs (und weniger bei einfachen Textdokumenten) eben doch sehr eng miteinander verbunden und nicht wirklich wiederverwendbar sind.

    Zumindest am Anfang wollen wir uns aber an die von der Web-Plattform vorgesehene Trennung von HTML und CSS halten und uns erst später mit möglichen Alternativen beschäftigen. HTML und CSS gehören für uns daher aktuell immer in getrennte Dateien.

    Das Document Object Model

  • Das DOM ist die Datenstruktur, die im Browser aus dem HTML-Code einer Webseite erstellt wird.
  • Es enthält Datenobjekte für alle HTML-Elemente des Dokuments (Überschriften, Absätze etc.).
  • Jedes Objekt beschreibt dabei Inhalt und Eigenschaften eines Elements.
  • Mit JavaScript kann die DOM-Struktur und somit der Inhalt einer Seite verändert werden.
  • Mit CSS kann daruf zugegriffen werden, um das Aussehen der HTML-Elemente zu definieren.
    • <html> <head> <title>Titel der Seite</title> </head> <body> <h1>Eine Überschrift</h1> <p class="main">Hier steht ein Absatz.</p> </body> </html>

    Wie wir in den gerade gezeigten Beispielen gesehen haben, werden Stylesheets verwendet, um die Darstellungsoptionen einzelner HTML-Elemente zu definieren. Hierzu bestehen die Stylesheets aus einer Reihe von Blöcken, in denen jeweils die zu gestaltenden Elemente ausgewählt und deren Eigenschaften festgelegt werden. Ermöglicht wird dies durch das Document Object Model (kurz DOM), das der Browser beim Laden einer Seite aus dem HTML-Code erzeugt und solange im Speicher behält, wie die Seite geöffnet ist. Es beinhaltet, vereinfacht gesagt, eine Baumstruktur mit den HTML-Elementen der Seite, auf die mit CSS und JavaScript zugegriffen werden kann, um den angezeigten Seiteninhalt zu beinflussen:

    • Mit JavaScript kann die Baumstruktur selbst verändert werden, um zur Laufzeit nachträglich neue Inhalte einzufügen oder alte Inhalte zu entfernen.
    • Mit CSS können über so genennte Selektoren die Einträge ausgewählt und ihre Darstellung festgelegt werden.

    Die Selektoren zur Auswahl der HTML-Elemente sind sehr flexibel und können sowohl einzelne als auch mehrere Objekte gleichzeitig auswählen. Auf dieser Seite werden die wichtigsten Möglichkeiten kurz vorgestellt.

    font-family: Liberation Sans, Arial, sans-serif;
    Legt die Schriftart für ein Element und seine Unterelemente fest. Werden mehrere Schriftarten angegeben, wird die erste gefundene verwendet. Immer vorhandene Schriften sind: serif, sans-serif, monospace, fantasy.
    font-size: 12pt;
    Legt die Schriftgröße eines Elements fest. Erlaubt sind entweder numerische Werte oder folgende Konstanten: small, x-small, large, x-large, …
    font-weight: bold;
    Legt fest, wie kräftig die Schrift erscheint. bold ist der normale Fettdruck. Es gibt aber auch normal, bolder und lighter.
    color: crimson;
    Ändert die Schriftfarbe des aktuellen Elements. Erlaubt sind alle Farbwerte, wie auf der nächsten Seite beschrieben.

    CSS kennt ziemlich viele Maßeinheiten. Auf dieser Seite sind deshalb gar nicht alle aufgezählt. Die wichtigsten sind aber alle dabei. Bei vielen davon handelt es sich um absolute Einheiten, bei allen anderen um relative Einheiten. Doch was ist damit gemeint?

    • Absolute Einheiten: Diese sind per Definition immer gleich groß. Ein Zentimeter ist ein Zentimeter ist ein Zentimeter. Beispiele: px, pt, cm, mm, …
    • Relative Einheiten: Beziehen sich immer auf einen bestimmten Bezugswert. Häufig handelt es sich dabei um die Schriftgröße oder um die Breite/Höhe eines anderen Elements. Beispiele: em, rem, %, vh, …

    Für die meisten Einheiten reicht die Kurzbeschreibung aus, um zu verstehen, was sie bedeuten. Manche sind dann aber doch ein wenig komisch, so dass wir sie uns lieber nochmal anschauen sollten. Zum Beispiel, was ist bitte schön ein „virtueller Pixel“? Ist ein Pixel denn nicht einfach ein Pixel auf dem Bildschirm? Leider nein. Früher war das mal so. Doch seitdem hochauflösende Bildschirme Standard geworden sind und es Smartphones mit höchst unterschiedlichen Displays gibt, ist es etwas kompliziert geworden. Auslöser war das iPhone 1, das 2007 auf den Mark kam. Es hatte eine Auflösung von 320x480 Pixeln, auf die man sich als Webdesigner einstellen konnte. Im Laufe der Zeit kamen dann aber immer mehr Geräte mit derselben Größe aber mit ganz anderen Auflösungen auf den Markt, auf denen die iPhone-Webseiten plötzlich viel zu klein aussahen. Deshalb haben sich die Browserhersteller einen Trick überlegt:

    Der Browser lügt, was die Bildschirmauflösung angeht! Ja richtig, der Browser lügt. Und zwar bis sich die Balken biegen. 🏗 Tatsächlich gibt es gar keine Möglichkeit, die wahre Bildschirmauflösung abzufragen. Denn jeder Browser meldet einfach eine – nach Ansicht des Herstellers – zum jeweiligen Gerät passende Auflösung und rechnet die Pixelwerte entsprechend um. Dadurch wollte man die alten iPhone-Webseiten retten und den Webdesignern Arbeit ersparen. Tatsächlich erreicht hat man das Gegenteil. Die Einheit px solltest du daher, wenn überhaupt, nur für die Dicke eines Rahmens oder die größe einer Schrift verwenden. Für alles andere solltest du aber besser andere Einheiten verwenden.

    Weitere interessante Einheiten sind em, ex und rem. Sie beziehen sich alle auf die aktuelle Schriftgröße. Ein em wächst also automatisch, wenn du die Schriftgröße des jeweiligen Elements vergrößerst. Für viele Dinge ist das ziemlich praktisch, da man immer ein gutes Ergebnis erhält. Zum Beispiel für Abstände, da der Betrachter bei einer größeren Schrift in der Regel auch einen größeren Abstand erwartet. em und ex richten sich hierbei nach der Schriftgröße des jeweiligen HTML-Elements. rem hingegen nach der allgemeinen Schriftgröße der Webseite, wie sie dem <html>-Element zugewiesen wurde.

  • Farbe ist keine universelle Eigenschaft von Objekten, sondern ein Sinneseindruck (die sog. Farbwahrnehmung).
  • Sie wird durch die Wahrnehmung elektromagnetischer Strahlung – dem Licht – ausgelöst.
  • Der sichtbare Bereich und auch der wahrgenommene Sinneseindruck unterscheiden sich für jedes Lebewesen.
  • Der sichtbare Bereich für Menschen liegt typischerweise zwischen 400 bis 780  Nanometer Wellenlänge.
  • Heute geht man sogar davon aus, dass die Menschen in der Antike die Farbe Blau nicht sehen konnten.
    •
  • Das menschliche Auge besitzt drei Arten von Zapfen zur Wahrnehmung der Farben Rot, Grün und Blau.
  • Hinzu kommen die Stäbchen, die nur auf die Lichtintensität reagieren („Nachts sind alle Katzen grau”).
  • Ihre kombinierten Reize bilden im Gehirn den Farbwahrnehmung genannten Sinneseindruck.
    • Lichtbrechung in einem Prisma Vergrößerte Pixel eines LCD-Displays
  • Grundsätzlich kann derselbe Farbeindruck auf unterschiedliche Weise hervorgerufen werden.
  • Einmal durch monochromatisches Licht von (mehr oder weniger) exakt einer Wellenlänge – die sog. Spektralfarben.
  • Oder durch polychromatisches Licht, bei dem sich Strahlungen unterschiedlicher Wellenlänge überlagen.
  • Die ersten beiden Bilder zeigen, wie ein Glas-Prisma das polychromatische Sonnenlicht in seine Spektralfarben bricht.
  • Das dritte Bild zeigt, wie ein typisches LCD-Display jeden Pixel aus roten, grünen und blauen Sub-Pixeln zusammensetzt.
    •

    Im Alltag haben wir es fast immer mit polychromatischem Licht zu tun. Dies machen sich unterschieliche Bildgebungsverfahren zu Nutzen, indem Sie entweder aus dem reflektierten Umgebungslicht bestimmte Wellenlängen filtern (subtraktive Farbmischung) oder durch Eigenleuchten meist rote, grüne und blaue Wellenlängen erzeugen (additive Farbmischung). Unten kannst du beide Verfahren ausprobieren und herausfinden, welche Farbeindrücke dabei entstehen.

    Additive Farbmischung
    LCD-Display, Röhrenbildschirm usw.
     Bei der additiven Farbmischung wird Licht unterschiedlicher Wellenlängen erzeugt. Meist handelt es sich dabei um die Spektralfarben Rot, Grün und Blau entsprechend der Funktionsweise des menschlichen Auges. Ein Computerbildschirm kann zum Beispiel nur exakt diese drei Farben erzeugen, indem jeder Pixel aus drei entsprechenden Sub-Pixeln besteht. Das Gehirn kombiniert diese dann letztlichen Farbeindruck.
    Subtraktive Farbmischung
    Drucker, Ölfarben usw.
     Jedes Material reflektiert bestimmte Wellenlängen oder lässt sie hindurch. Fensterglas beispielsweise lässt das für uns sichtbare Spektrum nahezu ungehindert durch, reflektiert aber Ultraviolett-Strahlung, weshalb man im Auto keinen Sonnenbrand bekommt. Dies nutzen die meisten Druckverfahren, indem sie auf eine Oberfläche wie Papier eine Materialschicht auftragen (die Druckertinte), die einen Teil des Lichtspektrums schlucken und nur den übrigen Teil durchlassen. Als Grundfarben werden hierfür meist Cyan, Gelb, Magenta und ein Schwarzanteil verwendet.

Unten kannst du den Unterschied sehen. Klicke unten auf eine Farbe, um ihre verschiedenen Schreibweisen anzeigen zu lassen. Mit dem Schieberegler kannst du zusätzlich ihre Deckkraft (den Alpha-Wert), die allerdings nur bei rgba()-Tupeln existiert, ändern.
