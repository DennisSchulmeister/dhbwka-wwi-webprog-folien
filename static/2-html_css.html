Spätestens seit der letzten Lerneinheit wissen Sie, was das World Wide Web ist und welche Techniken es nutzt. Die wichtigste Technik ist dabei sicher HTML. Besteht doch jede Webseite aus einer oder mehreren HTML-Dateien, die ihren Inhalt beschreiben. In diesem Kapitel wollen wir daher in die wunderbare Welt von HTML und CSS eintauchen, sodass Sie schon bald eigene Webseiten erstellen können. 🗐

Nach einer kurzen Einführung geht es auch schon direkt los und wir lernen das kleine Einmaleins von HTML: Die Syntax, die wir beim Erstellen von HTML-Dateien beachten müssen, sowie die wichtigsten dabei genutzten Elemente (Befehle). Hierbei lernen wir dann auch, welche Layout-Regeln zur Darstellung von HTML führen und wie diese bei der Strukturierung des Quellcodes unterstützen. Wir lernen daher, welche strukturgebenden Elemente es gibt und wie damit eine semantische Gliederung des Quellcodes erzielt werden kann. Zudem analysieren wir Unterschiede zwischen sichtbaren und unsichtbaren HTML-Elementen.

Da die Früchte unserer Mühen bis dahin aber noch relativ schlicht einher kommen, geht es dann gleich mit CSS weiter. Denn erst mit in CSS verfassten Stylesheets können wir uns bei der graphischen Gestaltung so richtig ausleben. Neben den Syntax-Regeln von CSS lernen wir daher das Document Object Model und darauf aufbauend allerlei nützliche CSS-Selektoren zur Auswahl und CSS-Anweisungen zur Gestaltung von HTML-Inhalten kennen. Dabei bewerten wir auch die Eignung verschiedener CSS-Techniken für bestimmte Designanforderungen.

Zum Schluss schauen wir uns dann noch ein paar Tipps aus der Praxis an. Beispielsweise wie Grafiken und Bilder für das Web aufbereitet oder als Hintergrundbild eingesetzt werden können. Abschließend wenden Sie Ihr Wissen in komplexen Übungen an, um eigene Layouts zu entwerfen und umzusetzen.
