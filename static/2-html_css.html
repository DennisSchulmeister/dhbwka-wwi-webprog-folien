  • die Einsatzgebiete von HTML als UI-Technologie kennen.
  • das Zusammenspiel von HTML, CSS und JavaScript in der UI-Entwicklung verstehen.
  • eigene HTML-Dateien erstellen und dabei die wichtigsten HTML-Elemente verwenden.

Spätestens seit der letzten Lerneinheit weißt du, was das World Wide Web ist und welche Techniken es nutzt. Die wichtigste Technik ist dabei sicher HTML. Besteht doch jede Webseite aus einer oder mehrerer HTML-Dateien, die ihren Inhalt beschreiben. In diesem Kapitel wollen wir daher in die wunderbare Welt von HTML und CSS eintauchen, so dass du schon bald eigene Webseiten erstellen kannst. 🗐

Nach einer kurzen Einführung geht es auch schon direkt los und wir lernen das kleine Einmaleins von HTML: Die Syntax, die wir beim Erstellen von HTML-Dateien beachten müssen, sowie die wichtigsten dabei genutzten Elemente (Befehle). Hierbei lernen wir dann auch, welche Layoutregeln zur Darstellung von HTML führen und wie diese bei der Strukturierung des Quellcodes unterstützen. Wir lernen daher welche strukturgebenden Elemente es gibt und wie damit eine semantische Gliederung des Quellcodes erzielt werden kann.

Da die Früchte unserer Mühen bis dahin aber noch relativ schlicht einher kommen, geht dann gleich mit CSS weiter. Denn erst mit in CSS verfassten Stylehseets können wir uns bei der graphischen Gestaltung so richtig ausleben. Neben den Syntaxregeln von CSS lernen wir daher das Document Object Model und darauf aufbauend allerlei nützliche CSS-Selektoren zur Auswahl und CSS-Anweisungen zur Gestaltung von HTML-Inhalten kennen.

Zum Schluss schauen wir uns dann noch ein paar Tipps aus der Praxis an. Beispielsweise wie Grafiken und Bilder für das Web aufbereitet oder als Hintergrundbild eingesetzt werden können.
